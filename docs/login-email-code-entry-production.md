# 邮箱验证码登录入口更新（2026-10-07）

邀请码注册可通过邮箱验证码完成，注册时未设置密码的用户再次登录时需要清楚的验证码入口。
登录页保持密码登录默认方式，在主登录按钮下方提供全宽的“用邮箱验证码登录”按钮，并显示
“未设置密码？可以使用注册邮箱验证码登录。”提示。按钮复用已有验证码表单，切换保留
已填写的邮箱；发送验证码仍由邮箱表单的提交按钮触发。

入口受现有本地登录、邮箱登录和验证码登录设置控制，登录请求进行中禁用，在双重验证
及安全密钥提示中隐藏。验证码功能关闭时，原邮箱登录链接继续可用。直接打开
`/login?mode=code` 可进入验证码表单。相关使用说明见[邀请码使用指南](academy-invitation-guide.md)。
