以下为原文摘录。仅证明摘录中说明的检查范围。

公开个人活动通过 `user-stream-item-above` 出口显示正文摘要和最多 3 张缩略图，
保留原生头像链接、分类、时间和展开/折叠。只隐藏已启用预览行的原生标题和摘要，
选择器需高于 Core 的用户活动样式优先级。草稿、书签、待审核内容、私信和通知不受影响。
最近讨论复用同一预览：有标题时只显示标题，无标题时显示两行摘要及一张缩略图。
内部标题标记和图片文件名根据原生 HTML 结构移除；正文中的普通编码仍保留。

正文在进入视口附近 200px 时加载，请求并发上限为 4，同一帖子请求去重，
共享缓存采用 50 条 LRU。预览实例只保留短摘要和图片地址。坏图自动尝试下一张，
全部失败时保留正文及帖子链接。隐藏内容继续遵守原有缓存失效机制。

本地两个主题 4、6 的 15 项 QUnit 测试、47 个断言全部通过；浏览器检查覆盖
20 个点赞状态、两次手机活动预览与原生展开、两次桌面最近讨论预览。所有本次源码
通过 `bin/lint --fix`，主题 JavaScript 和样式编译无错误。
