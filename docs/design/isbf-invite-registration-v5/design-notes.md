# ISBF 字符星云注册预览 V5

## 设计计划与建造前审阅

按用户确认的方案继续使用 `frontend-design`：保留字符粒子，点击注册后散开成星云，环绕居中表单；完成注册后表单消失，字符汇聚成对勾，对勾成形后停留 3 秒，再打开真实论坛首页。所有输入框内的占位文字与填写内容居中。

| 色彩角色 | 色值      | 用途           |
| -------- | --------- | -------------- |
| 正文     | `#17202a` | 输入、标题     |
| 页面     | `#ffffff` | 浅色背景       |
| 校园蓝   | `#1769aa` | 字符与主按钮   |
| 云色     | `#e7f2f9` | 浅色粒子层次   |
| 夜色     | `#101413` | 深色背景       |
| 夜间蓝   | `#72c5fa` | 深色字符与按钮 |

界面使用 Apple 系统字体、PingFang SC、Noto Sans CJK SC；标题 28–32px，输入 16px。字符保留 One／ISBF 的字母、数字及标点，使用缓存的等宽字形图集。表单、输入文字和短提示居中；输入边界与错误状态仍保持清晰。

唯一主要视觉是字符随注册进度变化的连续运动。星云采用不规则椭圆螺旋云带，含不同深度、厚度与密度，给输入区域留出清晰空间。首屏不添加说明段落，成功中心只显示对勾；跳转说明仅向辅助技术播报。

用户补充：对勾成形的同一帧，在后方启动数字、字母组成的瀑布流。使用更浅的蓝色、更小的字形、低透明度和不同长度的垂直尾迹；先绘制瀑布，再绘制高对比度的对勾。瀑布与粒子共用暂停控制，减少动态效果或 Canvas 回退时显示静态字符列。保持原有 3 秒跳转计时。

建造前审阅：保留原站品牌与蓝色，不添加新的彩色主题；原有字符成为星云材料，视觉变化直接回应注册动作。表单淡入与粒子散开统一编排，避免额外卡片和多余文案分散注意。V4 保留作对照，本版独立提供离线审核文件。

## 交互与实现约定

- 点击后散开约 1 秒；表单延迟 300ms、用 400ms 淡入。填写期间星云缓慢流动，输入获得焦点后降低流速；切换填写步骤不重复散开。
- 成功时表单 250ms 淡出并立即退出键盘操作，字符约 1 秒汇聚为稳定对勾；动画就绪事件启动唯一的 3 秒跳转计时，目标为 `https://isbf-one.com/`。
- 关闭、Esc 或导航取消当前过渡和未完成的模拟请求；未完成注册保留草稿。离开成功视图取消跳转，重新进入已完成注册时重新显示对勾并计时。
- 布局和可视区变化更新星云中心与表单避让区，手机键盘场景沿四边保留云带。沿用桌面 6800／触屏 3000 粒子、DPR 上限 2／1.5、30 帧/秒上限。
- 减少动态效果或手动暂停时直接显示静态目标；Canvas 回退显示静态品牌、字符云带与对勾，表单和 3 秒跳转仍工作。页面不可见时暂停动画，离开时清理资源。
- 注册校验仍是本地演示数据，最终导航需要联网；正式接入应使用 Discourse FormKit、UI kit、服务器校验与 i18n。

## 截图与验证

实现后记录实际截图审阅和浏览器验证结果，配套文件为 `verification.json`、`verify_preview.py` 与 `screenshots/`。

浏览器截图已检查 1440×900 的浅色与深色、390×844 的浅色及 320×720 的深色画面：字符云带围绕中央留白，输入框的占位文字居中。成功画面显示中央字符对勾，后方同时出现浅色数字字母列；整个表单退场，中心没有额外文案。窄屏将外层字符折回可视区四边，侧边云带与上、下星云继续可见；清晰区域按输入可读范围预留。

瀑布首轮截图的字形过细，已适当增大，最终检查了桌面与手机画面：数字和字母可以辨认，透明度与颜色仍低于对勾，保持清晰的前后层次。

注册成功的实际动画与自动导航已在浏览器中演练；完整检查对首页请求使用浏览器拦截，不访问真实论坛。跳转时间测试使用暂停的虚拟时钟，分别验证截止时刻前 1ms 不跳转、截止时刻恰好跳转。成功动画截图及瀑布冻结检查在载入页面前安装可控时钟，按帧推进后捕获，避免真实的 3 秒跳转提前结束检查；常规交互、粒子运动和系统动效偏好同时使用实际浏览器时钟验证。

最终 Chromium 151.0.7922.34 与 WebKit 26.5 各通过 36 项交互检查及 8 个尺寸／主题组合；页面错误与意外外部请求均为 0。覆盖字符散开、表单避让与居中、对勾汇聚、浅色瀑布的运动和暂停、静态回退、草稿恢复，以及 3 秒跳转的取消、重入和准确截止时刻。归档截图来自最终 Chromium 检查，详细记录见 `verification.json`。
