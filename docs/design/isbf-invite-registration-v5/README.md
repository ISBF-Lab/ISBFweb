# ISBF - One 字符星云预览 V5

解压压缩包，用浏览器打开 `preview.html` 即可体验，无需安装或启动服务。

首屏点击「通过邀请码注册」，字符散开为环绕表单的星云。所有输入框内的占位文字与填写内容居中。注册成功后整个表单消失，字符汇聚成对勾，同时在后方显示颜色更浅、更小的数字字母瀑布；对勾成形后停留 **3 秒**，自动在当前标签页打开 `https://isbf-one.com/`。

## 演示注册

1. 邀请码：`ISBF2026`。
2. 邮箱：`student@example.com`。
3. 验证码：`123456`。
4. 用户名：任意 2–20 个字符，例如 `campus_member`。

注册步骤使用本地演示数据，可以断网体验；最终跳转真实论坛首页需要联网。不会发送邮件或创建真实账号。登录按钮展示本地预览，条款与隐私链接打开原站页面。

## 操作

- 关闭按钮或 Esc 返回首屏，重新打开会恢复填写资料和步骤。
- 成功画面按 Esc 或切换页面可取消跳转；重新进入已完成注册时重新计时 3 秒。
- 右下角可切换主题或暂停、播放粒子；主题与动效操作不重置跳转计时。
- 系统减少动态效果时直接显示静态星云／对勾与瀑布；暂停同时冻结星云、对勾和瀑布，Canvas 不可用时使用静态回退。
- 填写期间，左下角「预览说明」可填入当前步骤的演示数据。

## 错误状态

| 输入                       | 演示结果                   |
| -------------------------- | -------------------------- |
| `EXPIRED2026` / `USED2026` | 邀请过期 / 已使用          |
| 其他邀请码                 | 邀请无效                   |
| `member@example.com`       | 邮箱已有账号               |
| `retry@example.com`        | 首次发送失败，再次提交成功 |
| `000000` / 其他六位数字    | 验证码过期 / 错误          |
| `admin` / `taken` / `isbf` | 用户名已占用               |

验证码支持数字键盘、粘贴、一次性验证码自动填充和 30 秒重发倒计时。

## 开发交接

HTML 内嵌 CSS、JavaScript、Logo 与 SVG 图标。注册控制器通过场景事件驱动粒子渲染器；渲染器完成对勾后发出就绪事件，表单退场完成后才启动跳转计时。运行标识阻止旧动画回调触发新页面的跳转。

星云位置按实际表单边界计算，留出输入区域，随窗口、表单高度和可视区变化更新。字体图集和首屏背景缓存，绘制最多 30 帧/秒；桌面最多 6800 个粒子，触屏最多 3000 个，像素密度分别限制为 2 和 1.5。

正式接入应使用 Discourse FormKit、UI kit、服务器校验与 i18n；本次提供独立设计审核原型。V4 保留作对照。

`design-notes.md` 保存设计与截图审阅，`verification.json` 保存检查结果，截图位于 `screenshots/`。`verify_preview.py` 是可选的 Python Playwright 检查脚本，支持 `--endpoint` 远程浏览器及 `--group registration` / `--group fullscreen` 分组；`--group effects` 单独检查星云、对勾和瀑布，`--filter` 按名称筛选场景。打开 HTML 不依赖该脚本。检查会拦截论坛首页导航，不访问真实论坛。
