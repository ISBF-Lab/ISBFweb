# ISBF - One 粒子注册预览 V3

按照 `frontend-design`，参考用户指定的 [MiMo 官网](https://mimo.mi.com/) 的字符点阵、图形变化与大留白，重新制作简约注册页面。沿用 ISBF 的蓝色、原 Logo 和深浅主题。

## 本地查看

1. 解压 `isbf-invite-registration-v3-preview.zip`。
2. 用浏览器打开 `preview.html`，无需安装、启动服务或联网。
3. 默认展示注册页。点击顶部「登录」，再点击「通过邀请码注册」，可以审核登录入口到独立注册页的完整路径。登录页没有邀请码输入框。

演示邀请码为 `ISBF2026`，邮箱可填写 `student@example.com`，验证码为 `123456`，最后设置 2–20 个字符的用户名。底部「预览说明」可以自动填入当前步骤的示例。

## 页面与动效

- 页面文字精简为当前标题、输入提示、主按钮和必要链接；错误信息按需出现。
- 字符粒子在「One」与站点光圈 Logo 之间缓慢变换，注册完成后组成确认标记。桌面支持鼠标经过时的轻微散开与回聚。
- 手机使用紧凑粒子区域和完整宽度的表单；粒子数量随显示区域调整。
- 粒子区域右下角可以暂停或继续。系统开启「减少动态效果」时默认静止，步骤切换仍显示对应图形；页面隐藏或粒子移出视口时暂停绘制。
- 底部三个图标切换系统、浅色、深色主题，选择保存在当前浏览器中。

## 演示数据

| 输入                       | 结果                       |
| -------------------------- | -------------------------- |
| `ISBF2026`                 | 邀请成功，忽略大小写       |
| `EXPIRED2026` / `USED2026` | 邀请过期 / 已使用          |
| 其他邀请码                 | 邀请无效                   |
| `member@example.com`       | 邮箱已有账号               |
| `retry@example.com`        | 首次发送失败，再次提交成功 |
| `123456` / `000000`        | 验证码正确 / 过期          |
| 其他六位数字               | 验证码错误                 |
| `admin` / `taken` / `isbf` | 用户名已占用               |

验证码支持键盘、粘贴、自动填充和 30 秒重发倒计时。返回或切换登录视图保留草稿；修改邮箱清除旧验证码；导航取消尚未完成的模拟请求。

这是设计审核用预览，所有验证在本地完成，不发送邮件、创建账号或消耗邀请码。登录操作展示说明弹窗，「进入社区」展示预览完成页。条款和隐私链接在点击后打开原站页面。

## 开发交接

`preview.html` 内嵌全部 CSS、脚本、原站 Logo 与图标。粒子使用 Canvas 2D、缓存字符图集、可复现的随机分布、最多 30 帧/秒和受限像素密度，不依赖第三方库；无法使用 Canvas 时展示静态品牌图形，表单继续可用。

正式接入时，将表单迁入 Discourse FormKit 和 UI kit，校验交给服务器，文字迁入 i18n，主题颜色读取站点变量。粒子视觉放入 ISBF 主题。此次产物为独立审核页面。

设计计划和实际截图审阅见 `design-notes.md`；浏览器结果见 `verification.json`；桌面、手机和各步骤截图位于 `screenshots/`。`verify_preview.py` 是可选的开发检查脚本，依赖 Python Playwright，支持本地浏览器和 `--endpoint` 远程浏览器；查看 HTML 无需安装该依赖。
