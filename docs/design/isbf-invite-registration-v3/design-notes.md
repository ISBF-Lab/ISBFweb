# ISBF 字符粒子注册预览

## 设计计划

参考用户指定的 [MiMo 官网](https://mimo.mi.com/) 当前页面，提取大留白、字符点阵聚合图形、图形间缓慢变化和紧凑操作按钮的表现方式。内容仍属于 ISBF - One 校园社区，注册任务仍为邀请码、邮箱验证与设置用户名。

| 色彩角色 | 浅色基础值 | 用途             |
| -------- | ---------- | ---------------- |
| 正文     | `#17202a`  | 标题、输入文字   |
| 纸面     | `#ffffff`  | 页面与表单       |
| 校园蓝   | `#1769aa`  | 操作与粒子       |
| 云色     | `#e7f2f9`  | 粒子区域的浅底色 |
| 夜色     | `#101413`  | 站点深色背景     |
| 次要文字 | `#596775`  | 帮助与条款       |

深色主题沿用原站正文 `#e7e9ea` 和强调色 `#72c5fa`。字体为 Apple 系统字体、PingFang SC 与 Noto Sans CJK SC；标题使用 28–32 像素中等字重，字段 16 像素，辅助链接 12–13 像素。所有标题保持整句同色。

```text
ISBF - One                         登录  注册

    字符粒子：One / 光圈 Logo        返回图标       三条进度线
                                    邀请注册
                                    [ 输入邀请码 ]
                                    [    继续    ]
                                    获取邀请码
                                    条款与隐私

预览说明                       系统 / 浅色 / 深色
```

桌面将粒子区域与紧凑表单并列，表单文字左对齐。手机将紧凑粒子区域放在表单上方。登录和注册共用同一个粒子区域，切换时保留动效与注册草稿。

## 建造前审阅

粒子的图形来自 ISBF 自己的名称和原 Logo，使用站点蓝色。主视觉采用字符与点组成的聚合、散开和轻微鼠标反馈，构成一个持续变化的区域。

页面不再承载宣传段落、功能列表或重复的成功提示。字段标签保留辅助技术可访问性，错误文字按需出现；用户名长度、验证码接收邮箱和条款保留在用户需要的位置。三条进度线对应真实注册步骤，完整阶段名称保留给辅助技术。

采用原生 Canvas 2D，字符预先绘制为图集，粒子数量随显示区域宽度调整。默认尊重减少动态效果设置，提供暂停按钮，并在页面不可见或粒子移出视口时暂停绘制。所有资源内嵌，下载后的单个 HTML 可离线运行。

## 实际截图审阅

在 1440 像素桌面和 390、320 像素手机上查看了浅色与深色截图。保留原站标识和蓝色按钮，粒子是唯一大面积视觉元素；表单没有卡片外框、宣传段落或重复品牌名。手机粒子高度收至 150–185 像素，使邀请码字段和继续按钮保持容易找到的位置。

第一轮截图确认「One」与原站光圈轮廓可以辨认，表单不与粒子重叠。完成页仅保留欢迎、用户名和操作。参考站截图属于内部研究素材，下载包仅包含 ISBF 页面及其审核截图。

## 实现要点

粒子图形从原站 Logo 像素、名称文字与确认路径采样，不使用参考站的图形或脚本。字符图集和背景点阵缓存后重复绘制；桌面最多 6800 个粒子，紧凑区域 3000 个；像素密度分别限制为 2 和 1.5。

系统减少动态效果设置可在页面打开后变化。绘制循环与媒体查询事件共同同步暂停按钮，状态不变时跳过 DOM 写入，保持实际播放状态与辅助技术状态一致。暂停后的配色切换和步骤变化仍重绘一帧。

浏览器检查覆盖真实表单错误、验证码输入与粘贴、重发倒计时、返回草稿、模拟请求取消、键盘焦点、主题记忆、粒子聚合变换、暂停恢复、移出视口与 Canvas 不可用时的静态回退。具体浏览器版本、结果和对应 HTML 摘要保存在 `verification.json`。
