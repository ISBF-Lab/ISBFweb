# ISBF - One 彩带预览 V6

解压后用浏览器打开 `preview.html`，无需安装或启动服务。

点击「通过邀请码注册」，字符散开为贴着表单外沿环绕的星云，所有输入文字居中。成功后表单消失、字符汇聚为对勾，蓝、金、青绿色彩带从左右下方喷出；对勾下方显示细线进度环和「5 秒后进入论坛首页」，5 秒后在当前标签页进入 `https://isbf-one.com/`。

## 演示注册

1. 邀请码：`ISBF2026`。
2. 邮箱：`student@example.com`。
3. 验证码：`123456`。
4. 用户名：任意 2–20 个字符，例如 `campus_member`。

注册使用本地演示数据，可离线体验；最终跳转真实论坛首页需要联网。不会发送邮件或创建真实账号。登录按钮展示本地预览，条款和隐私链接打开原站页面。

## 操作

- 关闭按钮或 Esc 返回首屏，重新打开会恢复填写资料及步骤。
- 成功页按 Esc 或切换页面取消跳转，重新进入重新庆祝、计时。
- 右下角切换主题或暂停、播放粒子和彩带；这些操作不重置跳转时间。进度环继续表达实际等待时间。
- 系统减少动态效果时显示静态星云、对勾、彩带和进度环；Canvas 不可用时仍可完成注册和跳转。
- 填写期间，左下角「预览说明」可填入当前步骤的演示数据。

## 错误状态

| 输入                       | 演示结果                   |
| -------------------------- | -------------------------- |
| `EXPIRED2026` / `USED2026` | 邀请过期 / 已使用          |
| 其他邀请码                 | 邀请无效                   |
| `member@example.com`       | 邮箱已有账号               |
| `retry@example.com`        | 首次发送失败，再次提交成功 |
| `000000` / 其他六位数字    | 验证码过期 / 错误          |
| `admin` / `taken` / `isbf` | 用户名已占用               |

验证码支持数字键盘、粘贴、一次性验证码自动填充及 30 秒重发倒计时。

## 开发交接

HTML 内嵌 CSS、JavaScript、Logo 和 SVG 图标。彩带与字符共用全屏 Canvas，沿用 30 帧/秒和 DPR 限制；桌面 6800 个字符、180 条彩带，窄屏／触屏 3000 个字符、80 条彩带。彩带只在成功时喷发一次。

控制器在表单退场且对勾成形后记录唯一的 5000ms 截止时间；进度环与导航读取同一截止时间。离开成功页清理导航及进度更新，旧场景的动画就绪事件不会触发新页面的跳转。

正式接入应使用 Discourse FormKit、UI kit、服务器校验与 i18n。本次提供独立设计审核原型，V5 保留作对照。

`design-notes.md` 保存设计及截图审阅，`verification.json` 保存验证报告，截图位于 `screenshots/`。可选的 `verify_preview.py` 使用 Python Playwright，支持 `--endpoint` 远程浏览器、`--group registration` / `fullscreen` / `effects` 和 `--filter` 场景筛选；`interactions` 组可单独检查首屏、导航与动效控制。打开 HTML 不依赖该脚本。检查拦截论坛首页导航，不访问真实论坛。
