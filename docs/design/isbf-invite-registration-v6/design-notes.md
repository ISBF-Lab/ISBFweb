# ISBF 彩带成功页预览 V6

## 设计计划与建造前审阅

继续使用 frontend-design。用户确认：删除字符瀑布，彩带从左右下方喷出，中央保留字符对勾，下方显示美观、合适的「5 秒后进入论坛首页」提示。注册首屏和居中输入沿用 V5；最新补充要求星云贴着表单外沿环绕，去掉外围留白。

```text
ISBF - One                                    登录

       彩带 ↗             ✓             ↖ 彩带

                  ◌ 5 秒后进入论坛首页
```

建造前审阅：视觉重点是一次注册完成的庆祝。三色细彩带从两侧向内上方喷出、自然旋转落下；对勾保持清晰，文字区域留白。等待提示只承担告知和计时功能，以细线和主题灰色保持克制，避免加入重复成功标题或独立卡片。用户未要求逐秒改写文字，因此文案保持固定，进度环表达剩余等待时间。

## 实现约定

- 彩带复用全屏 Canvas：桌面 180 条，窄屏／触屏 80 条，两侧均分；约 300ms 内喷发，旋转飘落，在 4 秒动画时间内淡出，不循环。先绘制彩带，再绘制对勾。
- 表单退场且对勾成形后显示提示，设置唯一的 5000ms 跳转截止时间；进度环与导航读取同一截止时间，目标为 `https://isbf-one.com/`。
- 主题切换和暂停彩带不重置跳转；暂停仅冻结彩带，等待进度继续反映实际时间。离开成功页取消计时和进度更新，重新进入重新庆祝并计时。
- 系统减少动态效果时使用静态彩带和进度环；Canvas 不可用时使用静态 SVG 对勾与三色彩带。仅向辅助技术播报一次成功及跳转信息。
- 沿用 30 帧/秒、桌面 6800／触屏 3000 字符粒子及 DPR 上限 2／1.5。提示位置随可视区、窗口和对勾边界更新；彩带避开文字区域。
- 星云避让边界改为表单实际边界，删除原有 24px 外扩区域，云带基础半径贴合表单半宽、半高；字形边界仍位于表单外侧，保留输入可读性。
- 注册继续使用本地演示数据。正式接入应使用 Discourse FormKit、UI kit、服务器校验与 i18n，本次交付独立审核预览，保留 V5。

## 截图与验证

实现后记录实际浏览器截图审阅与验证结果。检查对论坛首页导航使用浏览器拦截，不访问真实论坛；精确计时和成功动画截图使用预载可控时钟。报告为 `verification.json`，截图位于 `screenshots/`。

实际截图已审阅 1440×900 的浅色、深色，以及 390×844、320×720 的手机画面：星云沿表单四条边聚拢，去掉外围留白；输入保持清晰。成功时细彩带在两侧展开，对勾保持完整，14px 进度环与提示在下方居中，窄屏提示保持一行。彩带采用三色窄纸条、旋转和翻面，保留中央的安静区域。

用户要求减少重复检查，因此已通过的 Chromium 新增效果组直接复用；原有注册与导航组补充执行，WebKit 仅验证修改涉及的效果和准确 5 秒跳转。测试之后仅使用 Prettier 整理格式，验证记录同时保存浏览器检查版本与最终归档版本的 HTML 校验值。

最终 Chromium 151.0.7922.34 通过 37 项交互检查与 8 个尺寸／主题组合。WebKit 26.5 通过本次改动涉及的 8 项检查；手机缩放案例通过等待原生尺寸更新后再推进虚拟时钟修正同步，只复查了这一项，其余已通过结果复用。初次运行在手机断言处中断，前六项结果从 PASS 输出保留，运行时日志覆盖范围在 `verification.json` 中明确记录。所有检查的论坛导航均使用本地拦截。
