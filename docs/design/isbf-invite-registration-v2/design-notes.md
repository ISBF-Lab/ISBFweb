# ISBF 邀请注册第二版设计

## 设计方向

页面服务于 ISBF - One 国金校园社区，主要任务是让已有邀请码的人完成注册。按照 `frontend-design` 的流程，先确定视觉系统，再检查其与原站点和注册任务的关系。

视觉中心取自网站已有的光圈 Logo。将光圈演绎为带有玻璃与金属反光的立体雕塑，表达邀请打开社区入口。表单保持清晰、安静，让同一个品牌元素贯穿入口与注册流程。

## 颜色与字体

| 角色   | 基础颜色  | 用途                   |
| ------ | --------- | ---------------------- |
| 墨色   | `#17202a` | 正文、标题             |
| 白色   | `#ffffff` | 表单背景               |
| 银灰   | `#f3f5f7` | 品牌展示背景           |
| 校园蓝 | `#1769aa` | 主操作、链接、光圈反光 |
| 冰蓝   | `#dceef9` | 光圈材质、局部环境光   |
| 夜色   | `#101413` | 深色主题背景           |

深色主题沿用原站正文 `#e7e9ea` 和强调色 `#72c5fa`。颜色集中在主题变量中；所有控件读取变量。

中英文使用同一套系统无衬线字体：Apple 系统字体、PingFang SC、Noto Sans CJK SC、Microsoft YaHei。通过 12、14、16、20、32、56 像素的字号层级、适度紧排的标题和足够的正文行距建立节奏。全句标题采用一致的字重与颜色。

## 布局比较与选择

方案 A 将品牌光圈与表单左右并列。左侧通过材质和尺度呈现品牌，右侧让用户直接完成注册；两个区域共享一个页面背景与顶部导航。

```text
网站 Logo                         登录 / 注册   配色
──────────────────────────────────────────────────
品牌标题                         返回登录
说明                             注册进度
                                 当前步骤标题
       立体光圈                  输入字段
                                 主操作
校园动态 / 官方消息 / 日程         帮助与条款
──────────────────────────────────────────────────
设计预览                              演示说明
```

方案 B 将光圈置于全屏中间，点击后展开表单。这个方案需要多一次操作，也不方便在一张截图中审核页面和注册入口，因此采用方案 A。

桌面保持两栏、文本左对齐。手机将品牌标题、紧凑光圈和表单依次排为单栏；表单完整显示，不使用横向滚动。

## 建造前审阅

初步设想中的普通圆环没有足够的品牌关联，修订为与原 Logo 一致的五瓣光圈结构，并用材料反光而非背景装饰塑造立体感。邀请卡、悬浮功能卡片、标题单词染色与无意义的英文标签不承担注册任务，因此不进入本版设计。

大胆的视觉只集中在光圈。导航、进度、字段、错误和帮助保持简洁。进度编号对应真实步骤；动画用于一次入场和步骤变化，遵循减少动态效果设置。视觉审核时以桌面与手机、深浅主题的真实浏览器截图为依据。

## 截图审阅后的调整

实际浏览器截图显示，初稿光圈相对于标题偏小。修订时扩大光圈的展示比例、减少 SVG 内部留白，并略微缩小主标题，让品牌雕塑成为视觉中心。

光圈在验证邀请、设置账号和注册完成时改变姿态，完成时显示确认标记。主体按钮采用直接的操作文字；手机上将光圈缩为品牌区的一部分，让字段保持全宽。

最终审核覆盖桌面和手机的深浅色注册页、登录入口、邮箱验证、错误状态和注册完成页。Chromium 与 WebKit 分别通过 8 种布局及 19 项交互场景，检查结果保存在 `verification.json`，13 张审核截图位于 `screenshots/`。
