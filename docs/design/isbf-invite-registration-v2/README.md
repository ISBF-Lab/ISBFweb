# ISBF 邀请注册第二版预览

按照 `frontend-design` 重新设计。视觉中心来自网站原有的光圈 Logo，以五瓣立体光圈、金属反光和玻璃边缘呈现品牌。标题、分步表单和按钮保持简洁，沿用 ISBF - One 的蓝色强调色及深浅主题。

## 下载后查看

1. 解压 `isbf-invite-registration-v2-preview.zip`。
2. 用浏览器打开 `preview.html`。单个 HTML 已内嵌样式、脚本、SVG 光圈和网站原 Logo，可以断网查看。
3. 默认显示新版注册页。顶部“登录页”展示登录入口；点击“通过邀请码注册”进入注册页。登录页没有邀请码输入框。
4. 顶部提供自动、浅色、深色配色。自动模式跟随系统，手动选择会保存到当前浏览器。
5. 底部“演示说明”可查看示例，也可自动填入当前步骤的演示数据。

使用邀请码 `ISBF2026`，填写有效格式的邮箱，输入验证码 `123456`，再设置用户名，即可体验完整注册流程。光圈姿态随注册进度变化，完成时出现确认标记；减少动态效果模式下直接展示最终状态。

这是设计审核用原型。所有验证使用本地演示数据，不会发送邮件、创建账号或消耗邀请码。“进入社区”展示预览完成页，正式接入在设计审核后进行。服务条款和隐私政策仅在用户点击后打开网站原页面。

## 可审核的交互

| 演示输入                 | 展示效果                       |
| ------------------------ | ------------------------------ |
| `ISBF2026`               | 邀请验证成功，演示码忽略大小写 |
| `EXPIRED2026`            | 邀请码过期                     |
| `USED2026`               | 邀请码已使用                   |
| 其他邀请码               | 邀请码无效                     |
| `member@example.com`     | 邮箱已有账号                   |
| `retry@example.com`      | 首次发送失败，再次提交成功     |
| `123456`                 | 邮箱验证码正确                 |
| `000000`                 | 邮箱验证码过期                 |
| 其他六位数字             | 邮箱验证码错误                 |
| `admin`、`taken`、`isbf` | 用户名已被占用                 |

用户名演示长度为 2–20 个字符。验证码支持一次性验证码自动填充、粘贴和键盘输入；重新发送有 30 秒倒计时。返回上一步及切换登录／注册视图保留当前草稿；修改邮箱清除旧验证码；切换页面取消未完成的模拟验证。“重新体验”清空注册资料。

## 设计与开发说明

- 浅色正文 `#17202a`、背景 `#ffffff`、强调色 `#1769aa`；深色正文 `#e7e9ea`、背景 `#101413`、强调色 `#72c5fa`。控件通过统一颜色变量适配主题。
- 桌面采用品牌展示与注册表单双栏。手机展示紧凑光圈与单栏表单，保留完整输入空间。主按钮、主题切换和导航提供至少 44 像素的点击区域，字号避免手机输入时自动缩放。
- SVG 为代码绘制的品牌光圈演绎；顶部 Logo 使用原站图片。没有外部字体、图片库或脚本依赖。
- 动效集中在一次光圈入场和用户操作后的状态变化，尊重 `prefers-reduced-motion`。控件提供可见键盘焦点、表单错误文字和持久的辅助技术通知区域。
- 本包保留“邀请码 → 邮箱 → 六位验证码 → 用户名 → 完成”的既有原型交互。注册字段与正式服务器校验、邮箱验证码机制在接入时衔接。
- 正式接入时，交互使用 Discourse FormKit、UI kit、OTP 与 `a11y` 服务，文案迁移至 i18n 键，颜色读取站点主题变量。装饰视觉放在 ISBF 主题内。
- 设计计划与审阅记录见 `design-notes.md`；浏览器检查见 `verification.json`；截图位于 `screenshots/`。

`verify_preview.py` 是可选的开发验证脚本，需要 Python Playwright；查看 HTML 不需要安装它。脚本支持本地浏览器或通过 `--endpoint` 连接已有浏览器服务，运行方式可查看 `python verify_preview.py --help`。
