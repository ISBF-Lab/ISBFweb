# ISBF - One 全屏粒子预览 V4

## 下载后查看

1. 解压 `isbf-invite-registration-v4-preview.zip`。
2. 用浏览器打开 `preview.html`，可以断网查看，无需安装或启动服务。
3. 首屏展示全屏字符粒子，点击「通过邀请码注册」后在中央展开表单。

演示邀请码：`ISBF2026`；邮箱：`student@example.com`；验证码：`123456`。设置 2–20 个字符的用户名后即可体验完成页面。

右上角「登录」展示登录预览，页面只有「通过邀请码注册」入口，没有邀请码输入框。右下角可以暂停或播放粒子、切换系统／浅色／深色主题。展开表单后，左下角「预览说明」可以填入当前步骤的演示数据。

## 全屏与展开交互

- 粒子覆盖整个浏览器可视区，在 One、站点光圈 Logo 与完成勾号之间变化；鼠标经过背景时有轻微散开和回聚。
- 表单居中展开，使用轻薄半透明背景，保留周围的粒子；手机使用同一布局，短屏可自然滚动。
- 点击关闭按钮或按 Esc 返回粒子首屏；重新打开保留填写资料和当前注册步骤。模拟验证在关闭时取消，验证码重发倒计时按实际经过时间恢复。
- 浏览器前进、后退和 `#welcome`、`#register`、`#login` 链接对应首屏、注册与登录视图。
- 系统减少动态效果时默认静止，用户仍可手动播放。暂停后，主题和步骤变化仍展示对应的静态图形。

## 演示输入

| 输入                       | 结果                       |
| -------------------------- | -------------------------- |
| `ISBF2026`                 | 邀请成功，忽略大小写       |
| `EXPIRED2026` / `USED2026` | 邀请过期 / 已使用          |
| 其他邀请码                 | 邀请无效                   |
| `member@example.com`       | 邮箱已有账号               |
| `retry@example.com`        | 首次发送失败，再次提交成功 |
| `123456` / `000000`        | 验证码正确 / 过期          |
| 其他六位数字               | 验证码错误                 |
| `admin` / `taken` / `isbf` | 用户名已占用               |

验证码支持一次性验证码自动填充、数字键盘、粘贴和 30 秒重发倒计时。注册步骤之间返回、关闭和切换登录均保留草稿；修改邮箱会清除旧验证码。

这是设计审核用的离线原型，校验采用本地演示数据，不会发送邮件或创建账号。登录操作展示说明弹窗，「进入社区」展示预览完成页。条款和隐私链接在点击后打开原站页面。

## 开发交接

单个 HTML 内嵌 CSS、JavaScript、原站 Logo 和 SVG 图标。Canvas 位于固定背景层，前景控件保持正常交互；鼠标反馈排除表单和按钮。Canvas 跟随可视区大小变化，字符图集与背景点阵缓存，最多 30 帧/秒；触屏使用较少粒子和受限像素密度。

表单是页面内区域；主题和暂停按钮在展开后仍可操作。关闭恢复入口焦点，说明弹窗和预览说明优先处理 Esc。Canvas 不可用时显示静态品牌，表单继续工作。

正式接入时，使用 Discourse FormKit、UI kit、服务器校验与 i18n，颜色读取站点主题变量，装饰视觉置于 ISBF 主题。V3 保留为上一版对照。

设计记录见 `design-notes.md`，检查结果见 `verification.json`，截图位于 `screenshots/`。`verify_preview.py` 是可选的 Python Playwright 检查脚本，支持本地浏览器和 `--endpoint` 远程浏览器；打开 HTML 不依赖该脚本。

验证默认运行全部检查。资源受限时，可分别使用 `--group registration` 检查布局与前半流程、`--group fullscreen` 检查全屏动效、窗口变化及展开关闭行为。
