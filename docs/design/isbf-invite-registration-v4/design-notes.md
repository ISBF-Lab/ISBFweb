# ISBF 全屏粒子预览 V4

## 设计计划与审阅

用户已确认：粒子铺满浏览器页面，首屏点击「通过邀请码注册」后在中央展开表单。继续使用 `frontend-design`，以校园社区的 One 名称与原光圈 Logo 作为唯一主视觉。

| 色彩角色 | 值        | 用途           |
| -------- | --------- | -------------- |
| 正文     | `#17202a` | 标题与输入     |
| 页面     | `#ffffff` | 浅色画面和表单 |
| 校园蓝   | `#1769aa` | 粒子与按钮     |
| 云色     | `#e7f2f9` | 柔和视觉层次   |
| 夜色     | `#101413` | 深色页面       |
| 次要文字 | `#596775` | 辅助链接       |

深色沿用正文 `#e7e9ea`、强调色 `#72c5fa`。界面字体沿用 Apple 系统字体、PingFang SC、Noto Sans CJK SC；标题 28–32px、输入 16px。字符粒子使用缓存的等宽字符图集。

```text
ISBF - One                                  登录

           全屏字符点阵 / One / 光圈

               [通过邀请码注册]

                         动效 / 系统 / 浅色 / 深色

点击后：全屏背景保留，中央展开单一紧凑表单
               [返回] 进度条    [关闭]
               当前步骤标题
               [输入]
               [继续]
```

首屏不增加宣传标题、说明段落或功能卡片。中央展开的半透明表单用于保证输入可读性；周围粒子保留，表单附近淡化。桌面和手机使用同一布局，窄屏仅调整边距与内边距，不再使用独立粒子卡片。

建造前审阅确认：新的全屏范围和点击展开行为落实用户要求；蓝色、品牌、轻量文案与原网站连续。不会用额外装饰分散粒子主视觉。全屏为浏览器可视区，单页资源全部内嵌，保留前版供对照。

## 交互与实现约定

- 无 hash 或 `#welcome` 展示首屏，`#register` 与 `#login` 展示相应的中央页面区域；关闭和浏览器导航保留草稿与步骤，取消尚未完成的模拟请求。
- 表单为非模态页面区域，暂停、主题与登录导航仍可操作；关闭后焦点回到注册入口。说明弹窗和预览说明优先处理 Esc，再处理表单关闭。
- Canvas 固定于视口背景层，前景控件接收正常交互。鼠标反馈从文档读取位置并排除表单与控件；触屏不启用鼠标排斥。
- 桌面最多 6800 个粒子，宽度不超过 820px 或触屏粗指针设备最多 3000 个；像素密度上限分别为 2 和 1.5；绘制最多 30 帧/秒。保持系统减少动效、手动暂停、不可见暂停与静态回退。
- 手机允许页面自然滚动；Canvas 跟随可视区缩放，短屏和键盘收起／展开时控件可达。重发倒计时使用绝对时间，关闭表单期间停止轮询，重新打开恢复剩余时间。

## 第一轮截图审阅

在 1440×900、390×844 与 320×720 的浅色、深色画面中确认 Canvas 从视口左上延伸至右下，没有卡片边界。首屏仅显示品牌、登录、注册入口和图标控制。桌面表单宽 400px，手机分别为 350px 与 280px，保持居中且没有横向溢出。

表单背景淡化其下方的粒子，外侧仍保留完整画面；输入内容清晰。品牌使用独立的背景混合区域，使深色 Logo 在固定 Canvas 与前景层组合时正确显示。

完整浏览器检查与可复用截图保存在 `verification.json` 和 `screenshots/`，键盘占用空间通过缩小触屏视口检查。实际服务端接入属于审核后的后续工作。

测试浏览器服务在检查后关闭，避免版本迭代留下闲置实例。资源受限时使用验证脚本的 `registration` 与 `fullscreen` 两组；汇总时检查每组通过、场景名称唯一且总覆盖为 30 项。
