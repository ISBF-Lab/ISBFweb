# ISBF 邀请注册设计预览

本目录提供邀请注册的可交互 HTML 原型，供设计审核。页面沿用 ISBF - One 的 Logo、蓝色强调色和深浅色配色，并使用大留白、数字邀请卡与半透明表单卡片。

## 下载后如何查看

1. 解压 `isbf-invite-registration-preview.zip`。
2. 用 Chrome、Edge、Firefox 或 Safari 打开 `preview.html`，无需安装任何工具。
3. 默认展示新注册页。顶部的“登录页”可以查看移除邀请码输入框后的入口；点击“通过邀请码注册”进入注册页。
4. 顶部提供自动、浅色、深色切换。自动模式跟随系统配色；选择会保存在当前浏览器中。
5. 底部“演示说明”可以查看演示数据，也可点击“填入当前步骤的示例”。

HTML 的 CSS、脚本、图标和网站原有 Logo 均已内嵌，可断网打开。服务条款与隐私政策链接由用户点击后在新标签打开网站原页面。

## 完整体验

使用邀请码 `ISBF2026`，填写一个有效格式的邮箱，再输入验证码 `123456`，最后设置用户名即可完成预览。用户名长度为 2–20 个字符。“进入社区”展示预览完成页，“重新体验”清空注册资料并回到第一步。

这是审核用原型：所有验证都使用本地演示数据，不会请求站点注册接口、发送邮件、创建账号或消耗邀请码。注册草稿仅保存在当前页面内存中，刷新后重置；主题选择单独保存。

| 演示输入                 | 展示效果                       |
| ------------------------ | ------------------------------ |
| `ISBF2026`               | 邀请验证成功，演示码忽略大小写 |
| `EXPIRED2026`            | 邀请码过期                     |
| `USED2026`               | 邀请码已使用                   |
| 其他邀请码               | 邀请码无效                     |
| `member@example.com`     | 邮箱已有账号                   |
| `retry@example.com`      | 首次发送失败，再次提交成功     |
| `123456`                 | 验证码验证成功                 |
| `000000`                 | 验证码过期                     |
| 其他六位数字             | 验证码错误                     |
| `admin`、`taken`、`isbf` | 用户名被占用                   |

重发验证码使用 30 秒倒计时。验证码输入支持一次性验证码自动填充、键盘操作和粘贴；修改邮箱会清除原验证码。上一步和登录／注册视图切换保留当前草稿。页面切换会取消进行中的模拟验证，避免旧结果覆盖新步骤。

## 设计与接入边界

- 当前交付包括登录页入口预览及“邀请码 → 邮箱 → 六位验证码 → 用户名 → 完成”的注册体验。
- 线上公开配色已核对：浅色正文 `#17202a`、背景 `#ffffff`、强调色 `#1769aa`；深色正文 `#e7e9ea`、背景 `#101413`、强调色 `#72c5fa`。所有页面样式读取统一的配色变量。
- 网站现有注册启用了邮箱验证码，未启用随机用户名、注册姓名字段或额外用户字段，也不需要管理员审核。原型默认只设置用户名和显示默认头像，沿用 2–20 字符长度；完整用户名合法性和唯一性检查需在正式接入时由既有服务器处理。
- 手机使用单栏并收起邀请卡装饰，避免妨碍输入。主操作按钮至少高 44 像素，输入字号防止手机自动缩放；动效遵循 `prefers-reduced-motion`。
- 静态文案有 `data-copy` 标识，动态消息集中在内嵌脚本的 `messages` 对象中。正式接入时整体迁移至中英文 i18n 键，带链接的完整句子使用占位符。
- 正式接入时将入口与邀请码表单放入学院插件，注册行为衔接既有 `/invites/:token` 和邮箱验证码流程；控件复用 FormKit、UI kit、OTP 与 `a11y` 服务。装饰样式放在 ISBF 主题内，直接读取网站配色。
- 设计审核完成后再进行正式前端接入；本次没有修改线上页面、账号数据或现有登录实现。
