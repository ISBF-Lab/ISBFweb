# 首屏粒子呼吸加载动画

加载动画以登录页的光圈 Logo 为轮廓，用细小光点组成中央约 120px 的标识。
粒子每 3 秒轻微聚散、改变亮度，不切换字样，不响应鼠标、键盘或触屏。
浅色和深色模式直接继承网站的 `--tertiary` 与背景配色。
系统开启减少动态效果时保留静态粒子标识。

## 预览与资源

- `splash.svg` 是实际上传资源，内置 CSS 动画，不依赖脚本、字体或外部图片。
- `preview.html` 和 `preview.css` 提供独立预览；主题和减少动态效果跟随系统设置。
- `verification-chromium.json`、`verification-webkit.json` 和 `screenshots/`
  保存本次浏览器检查和视觉审阅结果。
- `source.json` 记录原 Logo 与 SVG 摘要、粒子数、分组数、种子和循环时长。

SVG 使用独立的 `isbf-loading` 类和动画名称，避免影响页面中的其他 SVG。
只给粒子分组设置缩放和透明度动画，粒子本身不创建独立动画。
生成时直接采样登录页使用的光圈图片，保留其不规则轮廓和内部留白。

## 接入与恢复

通过 Discourse 原生上传流程创建 SVG 资源，再将 `splash_screen_image`
设置为该上传资源。SVG 包含 CSS `@keyframes`，原生首屏因此直接展示动画，
不额外显示默认圆点。上传器保留 `style` 和 `circle`；首屏图片清理器只移除
SMIL 动画和显式宽高属性。

首屏结束时机由现有 `remove-splash` 初始化器控制，首次路由完成即移除。
不等待动画循环结束，不增加最低显示时长。站内导航、登录页粒子和主题字段
无需修改，也无需构建镜像或重启网站。

更新前记录原 `splash_screen_image` 上传 ID，并保存原上传资源。
恢复时仅将此设置改回原上传 ID；原值为空时改回空字符串。
不得恢复整库、覆盖主题或回退其他发布。发布证据保存到
`deploy-work/loading-animation-20261010/`，不包含凭据或完整运行配置。

该目录内的 `generate.cjs` 与 `logo-source.png` 保存生成过程及原始标识；
`verify_preview.py` 和 `verify_production.py` 保存浏览器检查方法。
`apply.rb` 使用原生上传、SVG 校验和 `SiteSetting.set_and_log` 接入，
`rollback.rb` 只在当前上传 ID 与摘要仍匹配本次发布时恢复原设置。
