# 首页和个人卡片头像框显示修复

修复源码提交：`2eb878d4227dee6009f839f681b0ad06f8e6223c`。
用户要求最终由其进行视觉核验，当前视觉状态待确认。

## 原因与修改

活动数据库主题 ID 4 的首页组件字段 227 仍有 `user-avatar-frame` 挂载点，
但头像为普通 `img`，没有 `avatar` 类。旧定位 modifier 只在头像框的直接父元素中
查找 `img.avatar`，因此无法找到首页头像。

原生个人卡片的 `user-card-avatar-flair` 出口带有额外容器，头像位于卡片头像区
内的链接中，也不属于框的直接父元素。两种情况都会提前返回，叠层一直保持隐藏。
这不是佩戴记录丢失，也不需要重新授予或重选。

唯一产品源码修改是插件的 `avatar-frame-position.js`：先定位最近的已有头像锚点，
在其中寻找 `img.avatar` 或锚点的直接头像图片，并监听该锚点的尺寸变化。
现有大小和偏移参数、白边扣除、动态/静态选择、点击穿透和 flair 层级继续使用原规则。
不改首页、卡片布局或现有款式的校准参数。
