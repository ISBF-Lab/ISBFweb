  继续使用原生DHorizontalOverflowNav及其滚动、箭头、键盘与选中行为，不通过全页裁切掩盖越界。

  “创建的话题”有链接和无链接两种统计状态均适用，剩余统计沿用既有网格自动排布。

  独立书签页、侧栏入口、书签数据与权限保持；不移除其他活动选项。
- 用户卡、资料顶部及一级导航、徽章目录、用户徽章页、后台和其他插件功能保持。
