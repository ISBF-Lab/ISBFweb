# 桌面账号菜单包裹布局

用户指出菜单偏在右侧三点按钮上方，并选择“一体包住”：菜单内容在上，原椭圆个人卡片留在底部，共享外框围住两者并按整张卡片中线对齐。仅扩展A01／C06的桌面完整侧栏账号菜单；折叠侧栏和手机保留现有浮出方式。来源与范围见[reference.json](reference.json)，用户原图保留私有目录。

定位、外框与行为

- DMenu的可选anchorElement回调只提供几何定位参照；空值或节点已移除时回退真实按钮。监听随参照切换并在销毁时清理；ARIA、触发、焦点及点击外部语义继续使用原按钮。
- 活动主题沿用24px面板、16px选项、8px内距、既有边框、配色与阴影。面板宽度等于实际卡片宽度加左右内距与边框，下沿在卡片外保留同样内距。
- 以现有卡片为前景、浮层为背景并预留底部空间，保持唯一卡片与稳定位置；菜单内容独立滚动，底部卡片保持可见。
- 关联账号、验证、跳转和退出处理保留；技术验证和最终视觉确认分别记录。

在隔离开发环境完成组件与页面验证后提交PR，通过准确提交CI和审查后增量上线；保留并发功能、完整运行环境、设置与数据。GitHub与生产端规范同步属于交付内容。
