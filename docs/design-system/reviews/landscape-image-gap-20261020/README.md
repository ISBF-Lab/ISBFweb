## 原因及修改边界

截图对应普通话题 209 的首帖 364。上传 HTML 声明缩略图为 690×347，原图为
3829×1926。信息流的 `DDecoratedHtml` 包装器没有 `.cooked`，没有应用核心
正文图片的 `height: auto`。主题限制了宽度，图片仍保留 347px 高度，
`object-fit: contain` 因此在图片框内留下空白，底部灯箱信息条跟随较高的外框。

仅在 `.isbf-feed-card__body` 中为普通图片补上自适应高度，沿用核心对
`.thumbnail`、`.ytp-thumbnail-image`、`.emoji` 的排除规则。
多图网格原有更具体的高度规则继续生效。视频、上传内容、数据接口和灯箱行为不变。
复用 A02/C09 的信息流布局、间距、圆角与既有响应式规则，没有新增设计变体。
