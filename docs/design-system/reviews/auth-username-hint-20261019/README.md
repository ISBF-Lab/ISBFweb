# 注册用户名提醒

用户确认在注册填写用户名时增加“用户名填写后不可更改”，随后指定使用站点主题蓝色。
本次只增加提醒，不调整用户名编辑权限或任何注册校验。

复用 A13 / C08 的认证说明排版：居中、13px、1.6 行高、既有字段间距；
颜色使用 `var(--tertiary)`，随当前主题及明暗模式变化。没有新增图标、提示卡片或全局视觉 token。

`CodeLoginForm` 增加可选的纯文本 `@usernameHint` 参数，默认不显示。
学院邀请码注册入口传入可翻译文案；用户名字段的两个互斥分支均支持该参数，
仅字段可见时显示一次。输入框的 `aria-describedby` 同时关联提醒和原校验错误。
原输入、随机用户名按钮、验证码、登录方式、粒子及成功跳转行为保留。

实际工作区源码和逐文件摘要见 `source-manifest.json` 及非执行 `sources/` 附件。
本次只确认该局部组合；技术检查不代表整个认证页新增视觉验收。
运行环境另存本次增量及其前置摘要，不能拿工作区主题覆盖活动数据库主题。

五个修改文件仅运行一次成功的 `bin/lint --fix`。编译和上线结果另见
[发布记录](../../deployments/auth-username-hint-20261019/README.md)。
