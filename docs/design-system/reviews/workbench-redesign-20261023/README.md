这是独立静态审阅示例，没有修改主题、业务组件、站点设置或生产数据，也没有部署。

## 已选择的方向

- 用户选择服务入口重设计、保留导航、全部服务同区、横向入口面板。
- `design-taste-frontend`：Editorial greeting，seed `20261023`，无重抽；完整方向保存在 `.taste-skill/direction.json`。
- 保留品牌配色和字体、A01 导航及 920px 功能区宽度。取方向的十二列对齐、16px 网格、单层面板；按本次选择保留名词标题，不加入问候、统计卡片或图表。
- 屏幕首先回答“现在有哪些工具可以使用？”；学习资源、简历、校友、商城的真实名称和用途形成本站身份。已开放服务整块直达，筹备服务同区展示。
- 三列、两列、单列按内容区域切换；末行补齐宽度。交互只包含导航、菜单及明暗预览，没有入场动画。

## 来源与限制

使用 A01/A08、C02/C04 的实际源码参考及语义变量。`source-manifest.json` 记录本次读取版本；没有将整个工作区视为已验收主题。原图标来自仓库现有 Font Awesome Free，授权见其包内 LICENSE.txt；没有外部照片、插图、视频或生成图像。

`fixture.json` 展示现有工作台中四种已接线服务全部启用的场景，并非线上当前配置。校友和其他插件的实际开关、鉴权、数据加载未接入示例。五项筹备服务的用途为待确认文案；不表示功能已经实现。资料库继续按当前工作台未接线状态展示。

品牌名使用主题设置默认值“国金综合平台”；没有取得线上徽标与当前字体设置，不伪造标志或账号资料。浅/深主色来自主题声明色板；`primary-medium`、`primary-low`、`primary-very-low` 是独立预览的可读回退值，不能提升为线上 token。手机底栏保留既有四项结构及字号，用实色底呈现静态参考，不复制背景模糊。上述差异不代表对导航的新设计批准。

`site/before.html` 是根据工作台源码重建的离线基线，**不是线上截图**。目标线上路由未登录返回 403。本示例不能证明服务器权限或完整功能回归通过。

## 检查方式

- 使用既有离线浏览器缓存，一个工具容器、0.5 CPU、192 进程上限；单浏览器、单页面串行截图。未启动完整预览论坛。
- `tools/inspect-serial.mjs` 来源于技能原始 inspector，仅调整辅助截图页生命周期及容器启动参数；各项测量和判定规则保留。原始页面测量结束后才打开辅助页，不同时保留两个标签页。
- `after/report.json`：1440、768、390px 的应用界面检查；`verification.json`：明暗、列数、真实链接、筹备状态、菜单关闭、焦点及减少动态效果。
- 示例将保持“待审阅”，技术检查通过不会使其自动成为 Approved。最终结果及审图记录见 `critique.md`。

## 复现

在仓库根目录执行 `node docs/design-system/reviews/workbench-redesign-20261023/tools/build.mjs`，重建 `site/index.html`、`site/before.html`、独立的 `example.html` 及来源摘要。独立文件的脚本在正文之后运行，直接打开时也支持明暗切换。浏览器检查脚本通过临时工具容器挂载 `/skill`、`/review` 和已有浏览器缓存执行。

生产实施时使用现有 Glimmer 组件、dIcon、DMenu 与翻译接口；这里的原生静态菜单只用于离线示例，不是可直接安装的主题组件。
