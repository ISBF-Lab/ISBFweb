# 实验布局：学、写、联、逛

[打开示例](example.html) · [电脑](screenshots/desktop-light.png) · [手机](screenshots/mobile-light.png)

用户于2026-10-23反馈首版过于常规，明确要求实验式布局。本版本是独立候选，不覆盖首版，不修改主题，不接入生产数据，不标记 Approved。

## 设计决定

- 屏幕的问题：从工作台可以直接去做哪些校园事务？
- 概念：把学习资料、写简历、联系校友、逛商城这四个实际去向，变成“学、写、联、逛”四个可以点击的大字。
- 桌面采用7/5列的错落索引：学习跨两行，简历与校友上下错位，商城横贯底部。手机为学习全宽、简历/校友双栏、商城全宽。
- 不用九个同款小卡片，也不增加装饰图片或虚构统计。五个筹备入口跟随各自的业务分区，仍在同一个工作台主体中显示。
- 保留首版中来自A01的导航、品牌字体与配色。巨字、错落排版、黑白反转与局部分组是本次实验候选，不提升为全站规范。
- 沿用 Editorial greeting（seed 20261023）的十二列对齐与单层色面，把原先均分入口的结构改成由内容重要性决定跨度。用户本次要求替换原先三/二/单列等大面板方案；没有为迎合习惯重新抽方向。
- 交互：大字和服务名称同属一个真实链接；悬停或键盘聚焦时，对应字标与箭头反馈，保留减少动态效果。手机不依赖悬停。

## 来源与边界

导航、颜色回退、示例字体及四个可用/五个筹备状态沿用上一级 README 的来源和限制。状态是审阅夹具，不是线上实际配置。没有新增外部素材；原导航图标使用现有 Font Awesome Free。大字是本地字体渲染的功能入口，不是新品牌标志。

新增视觉规则仍需用户看示例后确认。生产接入继续使用 Glimmer、dIcon、DMenu 和翻译接口；当前静态代码不能直接作为已批准主题安装。

## 重建

在仓库根目录执行：

```sh
node docs/design-system/reviews/workbench-redesign-20261023/experimental/build.mjs
```
