## 原因与局部规则

原生点赞由点赞按钮和点赞用户入口两个独立按钮组成。主题固定的36px/44px点赞目标，
加上人数按钮的内距，形成比热度更大的视觉间隔。
本人帖子则由同一个人数按钮展示爱心与数字；窄屏下默认居中还会改变爱心起点。

仅修改 `common/common.scss` 与 `stylesheets/reply-conversations.scss`：

- 复用A04/C09/C16的18px图标、`space-1`（4px）图文间距与五个等宽列。
- 保留点赞按钮36px/手机44px宽度和原有操作高度，通过计算偏移将图标留在统一列起点。
- 本人点赞入口左对齐；普通点赞、本人帖子、有/无赞数使用各自原生结构。
- 三层互动栏共用布局；评论展开按钮、子回复缩进、原生图标、点赞用户弹层及业务绑定保留。
- 平铺帖子沿用同一五列规则；已有附加“已解决”动作沿用右对齐的独立行。
- 保留原有字体、颜色、按钮状态和手机操作栏起点，不新增全局视觉token。

当前数据库主题比工作区更新。候选通过三方合并只应用本次样式差异，
未将工作区公共样式整体覆盖线上；确切字段、摘要和实际源版本见 `source-manifest.json`。
`source/live-before`、`source/live-candidate`、`source/live-styles` 保存实际数据库来源，
`source/workspace` 保存通过lint的工作区实现。
