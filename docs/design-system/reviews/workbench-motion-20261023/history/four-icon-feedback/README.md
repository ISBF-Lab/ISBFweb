# 工作台三列布局与图标动效预览

2026-10-23，用户放弃此前两版重新设计，要求在原工作台上增加动效并减少下半页留白。
本次用户进一步选定图标各有小动作：电脑悬停触发、手机有效点击后触发，替换整卡抬升、按压与波纹。
本目录仅交付离线预览；未修改运行主题，未连接生产数据，最终视觉验收待用户完成。

- [深色可点击预览](dark.html)

HTML 已内嵌样式、脚本和现有图标，无需服务器或外部资源。
鼠标放到学习资源、简历工具、校友网络、商城卡片的任意位置，可体验各自图标的小动作；手机完成点击后播放同样动作。预览链接只更新本地片段，可反复体验，不跳转线上。
其他五个占位入口没有链接、点击反馈或键盘焦点。更多菜单可以切换明暗外观，Escape 关闭并返回焦点。

## 局部设计约定

- 来源为 A01 页面壳、A08/C02 工作台入口；保留现有颜色、图标、字体和圆角。
- 三列，九项为三行；八项保持真实数量。桌面行高 `144–208px`，手机 `112–160px`，由屏高分配；长文案和短屏可以自然增长及滚动。
- 桌面、手机沿用 `600px` 响应式边界和 `14/8px` 网格间距。手机更多在面板后 `24px`，保留底部导航及安全区空间。
- 仅可用入口的 SVG 图标运动，卡片、背景色块和文字保持稳定。没有自动入场或循环动画。
- 鼠标进入整张卡片时播放一次；停留不循环，移出中途以 `120ms` 复位，重新进入可再次触发。手机与笔触由有效 click 触发，按住或滚动不播放；混合设备依据实际 pointerType 判断。
- Enter 激活也播放一次，保留静态焦点框。快速连点从当前状态重新播放，单个图标最多保留一个动画；失焦、隐藏页面及减少动态效果时清理。
- 使用原生 Web Animations API，不阻止默认事件或延迟导航；缺少 API 时静态展示。减少动态效果时不播放动画。
- 原版对照按当前工作台的 `4/3/4` 列及手机更多底部对齐规则重建，不能据旧候选的截图推断当前线上版本。

| 入口 | 动作峰值，随后自动复位 | 时长 |
| --- | --- | --- |
| 学习资源 | 转动 −8°，放大至 1.12 倍 | 360ms |
| 简历工具 | 上移 4px，转动 −4° | 320ms |
| 校友网络 | 放大至 1.14 倍 | 320ms |
| 商城 | 顶部为支点，依次摆动 −10°、7°、−3°、0° | 400ms |

前三项在动作时长 40% 达到峰值，商城四段均分；各段采用 `cubic-bezier(0.2, 0.8, 0.2, 1)`。

## 来源、复用边界与重建

`source-manifest.json` 保存实际输入和输出的 SHA-256。
上一版源码、独立页面、验证结果和按压截图已保存在 [history/card-feedback](history/card-feedback/ARCHIVE.md)，只作为旧版记录，不充当当前图标动效验收。
当前组件提供入口顺序、图标、局部色调和四个可链接目标；`fixture.json` 是功能全部配置后的演示数据，不声称是线上开关状态。
A01 壳的离线 HTML/CSS 来自前轮保存的静态壳适配，构建时剔除旧候选的全部主内容样式；未复用两版已放弃的主布局。
离线壳的品牌名和色板是前轮保存的示意值；`primary-medium/low/very-low` 不代表线上当前主题设置，也不新增全站 token。
旧参考 `.txt` 仍是非执行证据，未安装或覆盖主题。

运行 `node docs/design-system/reviews/workbench-motion-20261023/build.mjs` 重新生成三个独立文件。
`workbench.css` 和 `preview.js` 是本次候选源码；静态壳的 details 菜单只是离线适配，不是 DMenu、权限或业务路由的回归证据。
若后续接入运行主题，应保留原生链接导航、现有 UI kit/float-kit 行为及配置条件；本预览的本地片段目标不能直接用于生产。

检查结果、逐屏指标和限制保存在 `verification.json`、`critique.md` 与 `screenshots/`。
四种视口的明暗、9/8 项状态、四种图标动作、真实鼠标和触摸点击、键盘、滚动取消、快速连点、减弱动效和长文案由当前检查脚本验证。
`tools/check.mjs` 在无网络单浏览器中串行执行，`tools/check-icons.mjs` 检查新交互；关键帧保存在 `screenshots/desktop-icon-*.png` 和 `screenshots/mobile-icon-tap.png`。关键帧检查暂停真实输入触发的浏览器动画以读取峰值，不修改产品动画的时长。
`bin/lint --fix` 对本目录没有适用的核心规则，不将其退出成功视为 lint 覆盖；另执行实际源码的 Prettier、Node 语法及设计技能静态扫描。结果及已保留外观的检查器提示见 critique。
此记录仅确认预览实施范围，不将新布局或动效自动登记为 Approved，也不授予生产发布范围。
