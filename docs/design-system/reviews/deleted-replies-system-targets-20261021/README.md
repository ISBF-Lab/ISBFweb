# 删除回复与系统活动跳转（2026-10-21）

用户确认“合并简短提示”与“打开原帖正文”，随后明确要求实施。范围为普通话题的单层回复对话，以及个人公开活动的系统事件链接和已存在的系统楼层链接。

## 已确认规则

相邻、已加载、同级同父的删除叶子回复合并为“4 条回复已删除”。默认收起，展开后每个楼层占简短一行；单条没有展开或收起按钮。普通回复、分页缺口和父级变化会中断合并，不推算未加载条数。删除父回复保留正常后代。管理操作使用每行更多菜单，查看原文和恢复保持原权限。定位会自动打开对应组并沿用现有两秒高亮；恢复成功清除占位状态并即时重新分组。

公开活动仅按 post_type 和 action_code 判断系统事件，相关入口链接首帖；其他活动链接保持原楼层。服务端只把已存在且可见的 small_action 目标解析为首帖，返回 resolved_target_post_number: 1；客户端保留 sort、移除 context 并规范网址。隐藏、已删除且无权查看、私密或不存在的目标仍按正常权限/错误处理。请求失败使用既有错误页，不返回空模型。

## 复用边界与来源

复用 A01/A04/C09 及已批准回复对话的直线支线、42px头像、五项操作、语义色和字号。简短提示只使用现有 muted、font-sm、space-2/3 以及44px触控目标；不新增全局token。使用 DButton、DMenu、DDropdownMenu、PostCookedHtml 和原生恢复接口，无数据库迁移。

实际源版本和每文件前后摘要见 [source-manifest.json](source-manifest.json)。补丁及带 .txt 后缀的附件只作审阅证据，不能作为主题安装包。本次接受不扩展为整页或全部管理菜单的视觉批准。
