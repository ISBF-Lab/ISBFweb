## 设计与实现边界

复用已有C01/C07、D02/D07及语义token：16px外框圆角、1px边框、16px内距，普通文字按钮pill/44px/15px/600。颜色跟随站点明暗语义变量。宽度、任务内容与提交接口保留；手机四周16px加安全区是本次明确确认的新适用规则，替代旧D07的手机全宽外框。

公共样式直接覆盖前台DModal与dialog服务产生的确认框，覆盖组件内直接渲染的DModal及新插件，移除路由和组件名单。后台通过`admin-interface`排除；float-kit、聊天动作菜单保留菜单用途；用户卡、图片查看器、编辑器、独立认证页和`/join/`保留各自布局。

个人日历、课程申请及资源/资料库目录编辑迁入DModal和FormKit。日历保留本地时间转换、全天事件UTC开始与排他结束、POST/PATCH、私有备注编辑分流；目录保留名称限制、父级、原接口、审核回执及回调。提交中锁定操作，失败保留字段。

## 逐项处理

| 区域 | 原问题 | 处理方式 |
| --- | --- | --- |
| 普通话题中的跳转、分享、书签及确认框 | 受旧页面和组件名单限制，普通入口得不到统一外观 | 共享前台选择器自动覆盖，原动作及业务宽度保留 |
| 头像、邀请、安全设置、群组及其他原已覆盖弹窗 | 外观依赖名单和页面状态 | 继承同一公共层，页面范围仅负责页面布局 |
| 举报 | 手机底部直角、外框局部重复 | 移除局部外框，统一四角和手机边距，保留举报动作 |
| 简历确认及分享编辑 | 按钮8px圆角、外框和内距独立维护 | 删除重复chrome，保留业务宽度和文本 |
| 学习资源与目录编辑 | 页面内手写dialog，焦点和退出自行处理 | 使用DModal/FormKit；父级选择器支持提交中禁用 |
| 个人日历编辑 | 手写遮罩、固定层级及独立表单 | 新`ISBFCalendarEntryEditor`复用模态服务与FormKit |
| 官方日历、备注、资源分享及其他插件 | 各自继承默认外框，部分保留旧选择器 | 自动继承共享外观，删除失效的旧容器选择器 |
| 核心及扩展的基础样式 | 其他主题及工程行为仍需要默认规则 | 精确摘要登记其回退声明；当前主题统一覆盖 |

机器清单由`script/check-isbf-dialogs.mjs --report`生成，保存每个候选的路径、源码摘要、实现方式和验证范围。候选包括共享原语及非模态表面，不等于同等数量的用户弹窗，也不代表每个插件业务流程都已单独验收。
