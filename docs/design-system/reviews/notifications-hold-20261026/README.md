# 通知页长按标读按钮

用户提供 HoldButton 的 JavaScript／CSS 完整源码，并确认实施方案：电脑端将“全部标为已读”移至三点左侧，手机端同排显示“全部已读”；长按300ms，填充使用站点蓝色，待机跟随网站配色，高优先级通知保留原确认框。来源与参数见[reference.json](reference.json)。当前开发验证已完成；PR通过CI并合并后增量发布生产，最终视觉待用户验收。

## 组件与交互

复用A05／C01／C13、站点surface/text/hover/accent/contrast及pill圆角；按钮与菜单入口保留44px触控高度，操作间距space-2。标题在空间不足时省略，业务按钮与菜单保持一行。手机仍使用文字按钮，保留完整可访问名称。

`DHoldButton`为基于DButton的原生UI kit组件，不引入新的npm依赖。线性向右填充、6px波浪、发光、0.97按压缩放及完成文字过渡仅用于本次确认的按钮组合；提前释放用200ms回退，成功状态保持1200ms。颜色通过主题变量传入，不固定浅色或深色色值。

未满300ms松手、滑出、触控滚动、丢失捕获、失焦、页面隐藏或组件销毁均不执行动作。空格和Enter同样要求长按，Escape取消；普通click不提交，短按通过可访问服务提示所需时长。系统减少动态效果时移除波浪、缩放与脉冲，确认时长保留。

按钮在长按后等待异步动作结果，只有成功才显示“已全部标读”。有高优先级通知时复用原确认框；取消返回idle，确认提交后等待请求结果。失败沿用现有错误与重试。请求中的重复操作被阻止，保留原有版本判断，避免覆盖请求期间收到的新通知。完成或取消确认后恢复焦点，不抢夺已移至其他控件的焦点。
