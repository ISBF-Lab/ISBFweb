## 补充修复

通知菜单使用稳定宽度，数字／圆点之间移动时不再受文字或高亮的亚像素尺寸变化影响。
压力检查在正常与0.5px内距下均记录到横坐标和宽度变化0px。
帖子举报按钮的双层容器已纳入共享选项识别，背景保持透明并使用16px圆角，
实测按钮宽163.015625px、高亮宽163.016px，点击回调回归通过。
探索工具栏让类别／标签分配剩余空间，热门／新建话题保留完整文字和44px触控尺寸；
320、390、768、900和1440px明暗模式检查通过。

长菜单复查发现定位器的内联max-height覆盖了共享上限，已改为提供可用空间变量，
由共享样式统一限制55dvh与实际剩余空间。
