# 工作台配置的设计范围

2026-11-20 用户明确确认在现有主题后台增加统一入口顺序、图标与五个预设色板；
复用原生对象编辑器的上下移动、保存、恢复默认和已有后台权限，不改变 Admin 布局。
只扩展 A08/C02 工作台，不批准其他页面或新业务入口。

基线为 `ISBF-Lab/ISBFweb` `e69bfa59825a89800215a765ecf5091a678eca0d`；
本功能分支 `codex/workbench-entry-configuration`。实际源码是
`themes/isbf-campus-feed`，参考附件和迁移快照保持原字节。

来源为现行 `workbench.scss`、[分端布局记录](../workbench-layout-20261024/README.md)、
[指南图标增量](../guides-20261108/README.md)及本次已确认需求。
保留两端各自布局、600px 导航分界、占位和真实权限；名称与链接继续由业务提供。

五个预设为默认、主题色、薄荷绿、琥珀色、紫色。默认无覆盖；其余复用现有 accent、
`#35b595`、`#e5a659`、`#9480d8`，底色 15%/19%/21%/19% 与 surface 混合，
传统图标按同一比例与 text 混合。玻璃背板使用原 92% 混合，前景采用原亮度判断。
这些变量只定义在所选工作台入口内，不新增全站 token，不影响真正的后台。

图标复用共享选择器和资源机制。原生实心 SVG 使用 currentColor，已有线条 SVG 保留 fill=none。
本轮用户不批准 Core 修改，完整图标库搜索保留未实现；现有子集选择和清空照常可用。
原生 enum 仍显示稳定英文值，中英文说明提供色板映射。

实现、定向静态检查与设计确认分别记录，尚无独立开发站的最终视觉或原生集成验收。
离线 Chrome 56 组断点/布局/明暗静态组合通过，最低标签及显式色板图标对比度 4.909:1；
该预览未加载原生 sprite、后台表单或 WebGL，不能替代原生资源、权限和保存验收。
完整格式、合并、优先级、测试命令与环境阻塞见
