# 个人活动与总结正文预览修复

2026-10-19，用户确认采用正文摘要替代无标题帖的内部占位标题；活动页最多显示三张缩略图，总结页维持紧凑文字列表，并要求验证后直接上线。范围为 `/u/:username/activity` 的公开活动与 `/u/:username/summary` 的话题、回复及热门链接条目。

## 原因与实现

历史 `UserAction` 记录可能没有 `post_id`，仍提供 `topic_id` 与 `post_number`。原资格判定将这些记录排除，页面落回原生标题和图片文件名摘要。Gin 的一次只读样本包含45条活动，其中16条缺少帖子ID；样本仅用于确定数据形状，未修改历史内容。

活动预览接受有效帖子ID或有效主题/楼层组合，通过已有服务器权限接口按需读取熟化正文。缓存使用接口返回的实际帖子ID，主题/楼层别名上限50项，共享最多4个并发请求；隐藏或编辑失效后，较早返回的正文不会重新进入缓存。保留线上原有投票加载器的按用户缓存和30秒有效期。

总结页增加 `user-summary-topic-title` 插件出口，由主题在无标题时提供两行正文摘要；热门回复和热门链接使用自身楼层，热门话题使用第一帖。有标题的条目保留原有标题链接，日期、点赞、外链统计和原始目标继续由原生组件提供。纯图片内容使用已有“图片”翻译回退，总结页不插入缩略图。

## 设计来源与范围

复用 A12/C12 的活动作者、分类、时间、原生展开、正文和最多三图规则。总结页两行文字的选择来自本次用户确认，链接颜色沿用 `--isbf-v2-accent`。没有增加颜色、间距、圆角或全局组件变体。A11资料顶部、右栏最近讨论、私信、草稿、书签、待审及通知不在本次修改范围；本次技术核对不提升其他区域的 Approved 状态。

工作区版本与摘要见 [source manifest](source-manifest.json)，快照位于 `source/`。线上合并版本须以独立发布记录为准：数据库主题包含工作区以外的投票扩展和其他已部署修改，不能直接整目录覆盖。
