# 论坛助手独立对话工作区

用户否定原生会话页的外观，要求删除右上角聊天和个人头像入口，并要求提问、回答、追问留在助手主界面。随后明确选择「独立对话工作区」和「轻量对话气泡」，批准实施完整方案。

## 设计与复用范围

- 入口保持 `/discourse-ai/ai-bot/conversations`，会话使用 `?conversation=<id>`。顶部为品牌及返回工作台，桌面左侧历史、右侧消息；1023px 及以下切换为对话／历史两个单列视图。
- 用户问题靠右显示浅底气泡，助手正文靠左展开。来源链接、Markdown、长内容与已有历史保留。模型输出的纯文本站内帖子地址在清洗后的文本节点中补成链接，代码块与既有链接保留；跳转仍执行目标帖权限。没有话题标题栏、收件人、邀请、时间轴或帖子操作栏。
- A01/C04 提供实际品牌组件、1260px 最大宽度、260px 侧栏和 600px 正文宽度变量；本次用户选择批准该工作区组合，不扩大既有 shell 的批准范围。
- 颜色、字体、4/8/12/16/20/24/32px 间距、8/16px 与 pill 半径复用 V2 语义变量。欢迎标题复用已记录的功能区 28–34px 层级；机器人图形复用已有工作台图标。用户气泡最大 85% 为本工作区局部排版，不能作为全站 Card 规则。
- 按钮使用 DButton，输入使用 FormKit；手机历史是同一工作区的列表视图。键盘焦点、Escape 返回、软键盘可视高度和安全区均在此页面处理。
- 既有 C02 工作台入口及已确认的问答策略保持原范围。本轮不新增改名、删除、分享或模型切换。

## 行为与数据

底层复用既有会话存储、NewPostManager、Guardian、论坛助手请求和额度。专用 API 只接受正文，服务端固定 agent/model；列表、详情、追加消息、取消均限本人会话。更改过参与者的既有会话保留只读能力。

前端独立管理消息、按账号和会话隔离的草稿、受限流式订阅与完成通知。拒答、澄清、失败、退款及取消的终态同样会更新界面；切换或离开时撤销当前订阅，不自动重发失败请求。旧的本人助手话题链接进入此工作区，其他话题继续使用原流程。
