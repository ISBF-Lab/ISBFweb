# C22 活跃等级管理

本轮用户在 2026-11-03 的实施方案中明确选择“沿用当前后台样式”，随后要求实施。
该确认允许本页复用现有后台卡片和表单组合；不把其他原生后台界面或未验收稿件作为全站设计标准。
设计方案已确认，开发技术验证及最终用户视觉验收分别记录。

## 批准范围

- 独立入口 `/admin/plugins/discourse-academy-roles/activity-levels`，只有开发者可访问。
- 全局降级开关、每级名称和条件、折叠高级区、增删等级、保存／重置、重算汇总及失败重试。
- 复用 AdminConfigAreaCard、FormKit、DButton、DPageSubheader，条件选择器使用共享 DSelect。
- 删除等级走既有 dialog 服务，确认文案显示受影响人数及重新归级规则。
- 公开资料和后台用户页仅追加可选等级名称，保持原位置和文字样式。

页面没有新颜色、字体、间距、圆角、阴影或菜单外框。明暗模式跟随现有变量，窄屏使用原生后台和 FormKit 响应式行为。表单操作不套用栏目页头的窄屏三点收纳规则。

## 来源与版本

原生 `frontend/discourse/admin/components/admin-config-area-card.gjs` 及其完整后台样式提供卡片；
同插件现有 `academy-moderator-permissions.gjs` 提供后台 FormKit 组合参考。
来源快照在 `references/`，逐文件摘要、核心版本和最终实现摘要在 `source-manifest.json`。
这些附件是非执行证据，不作为替换活动主题或应用源码的安装包。

菜单外观继续来自活动主题 `stylesheets/dropdowns.scss`，遵循[共享下拉契约](../../dropdowns.md)。
只调用既有 dialog 服务，没有修改弹窗模板或样式，因此不新增弹窗例外。
捕获的应用没有 `lint:dialogs` 命令，本轮不把该项记作通过。
