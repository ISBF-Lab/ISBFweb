## 最终规则

- 原生主题后台提供 `workbench_layout_mobile` 与 `workbench_layout_desktop`，均有 `traditional` / `glass`。以 600px 为界，默认手机传统、电脑玻璃，统一对全站用户生效。
- 传统手机四列、10 个模块三行；玻璃手机使用紧凑间距。375×667 常规字号首屏完整，较小屏幕或放大文字允许滚动。
- 玻璃图标与名称共用入口前景。移除 CSS 背景模糊，折射材质 `uSoft=1`，保留高光、入场及指针动效。减少动态效果、WebGL 不可用和上下文丢失均有回退。
- 未满行使用 `flex-start` 与第一列对齐；最大宽度和自动外边距保留整组居中。WebGL 从入口 DOM 读取位置，玻璃、图形和文字同步。
- 24 个可选 HEX 设置分别控制电脑玻璃的浅色/深色面板、默认背板和 10 个模块。单模块覆盖优先，留空跟随默认或主题；手机与传统模式沿用原配色。
- 同一组入口 DOM 支持两种布局。传统模式不创建图形资源；跨断点和销毁时释放观察器、监听、动画与 GPU 资源。

这些是 C02 工作台局部变体，不成为全站通用卡片或颜色 token。
