# 手机发帖分类菜单滚动与搜索修复

手机发帖分类菜单出现长列表无法滑动、输入搜索时抽动。本轮恢复C06菜单滚动与搜索语义，使用C08已有输入字号；面板24px／选项16px圆角、8px内距及其配色继续复用共享契约。

选项集合独立滚动并允许flex收缩，搜索栏保留尺寸，面板裁剪溢出并从触发边排列。共享结构选择器明确覆盖基础表面和核心展开态规则，避免旧的外层滚动／居中继续生效。发帖分类菜单的原有高度预算集中在dropdowns.scss，同时服从55dvh及当前可用空间。

向上菜单原先按旧高度写入绝对纵向偏移，筛选后要等下一次观察器更新才重新定位，实际页面记录到搜索栏偏移28px。核心SelectKit改为按已测得的下沿定位并通过自身高度百分比抵消实时高度变化；内容重排期间也保持触发边。向下菜单沿用顶部锚定，真实分类值和回调继续由原选择器处理。原生上下两向回归主动暂停下一次定位更新，验证中间帧中的搜索位置、焦点及选值。

手机搜索输入复用font-md（当前16px），选项保持15px。iOS会对小字号输入自动聚焦缩放，使用现有16px输入字号避免额外缩放，参见[官方Web无障碍说明](https://docs.flutter.dev/ui/accessibility/web-accessibility#viewport-zoom-and-mobile-text-inputs)；用户主动缩放保留，不新增字体token。

实际产品涉及核心定位与高亮适配、两份主题样式。内部滚动通过成对注册／清理的scroll监听刷新现有高亮，不改变焦点或选值。共享高亮可选viewportSelector把光标绘制在原选项集合内；部分或全部滚出集合时由原生overflow裁剪，搜索栏不会被滑动光标覆盖，减少动态效果的规则同时保留。两组原生回归及手机页面验证结果、失败迭代和覆盖边界见[validation.json](validation.json)，交付源见[source-manifest.json](source-manifest.json)。本地早期半缩放夹具、热重载登录错误和重复草稿遮罩均有私有诊断记录；它们不记为通过，也不改写产品异常处理。

使用独立工作树和开发验证主题，保留PR100账号菜单工作树；已合并的账号菜单提交13d66d6作为本次修复的第二父提交整合，根运行源按文件摘要及所属段落合并，保留账号包裹和其他并发增量。截图仅在私有目录保存。准确提交的CI及审查通过后按用户既有授权增量发布，保留完整运行环境、插件、数据库主题、设置及数据，并同步生产规范。

## 开发验证

最终原生ComboBox回归5项／18条断言、主题滚动回归4项／34条断言通过，客户端异常0。新增共享高亮接口的完整类型检查0错误，定向lint和菜单规则通过。定位断言保留1px上限；初始化先等待字体、初始定位与展开动画，再暂停下一次定位更新。部分滚出和全部滚出的高亮都随集合裁剪，减少动态效果规则保留。

前轮已通过的实际手机页面验证直接复用：Chromium触控及iPhone UA，390×844、390×520和320×520；原生手势可滚动161px，搜索栏位移0；320／390px连续输入各56帧，触发边漂移均为0、焦点保留。该页面流程不因仅涉及光标裁剪的后续修复重复执行。真实iOS系统键盘未模拟，不将该覆盖称为物理设备Safari验证。其他已通过的无关套件不重跑；所有CI门禁保留，准确提交CI及审查仍为发布前提。
