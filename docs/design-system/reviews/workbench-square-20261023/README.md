# 工作台十入口方形布局与图标动效

2026-10-23，用户确认电脑五列、手机两列，并指定卡片为方形；随后明确取消独立预览，要求直接接入网站并上线。

发布候选从活动主题 ID 4 提取，两次合并期间其他开发者的日历样式更新均保留。随后发布的个人页组件和样式也保留。历史参考附件保持原始字节。
完整实际源码、前后摘要和版本见 [source-manifest.json](source-manifest.json)；线上记录见 [发布记录](../../deployments/workbench-square-20261023/README.md)。

## 局部布局规则

- 正常文案下卡片宽高为 1:1；不按屏高拉长卡片。电脑宽屏五列两行，手机两列五行，自然滚动。
- 面板内容宽度至少 696px 为五列，394–695px 为四列，更窄为两列；手机不超过 600px 时固定两列。
- 采用按行换行的 Flex，间距桌面 14px、手机 8px。末行不足时居中且保持方形，不造空卡片、不修改 DOM 顺序。
- 复用既有 62/44px 图标底块、27/22px SVG、15/12px 文字及原有圆角；四列紧凑布局复用较小组合。没有新增全站颜色或尺寸 token。
- 手机更多菜单位于面板后 24px，保留原组件、底部导航和安全区。
- 用户进一步要求方形，因此首屏自然留白优先于之前的按屏高铺满方案。

## 交互规则

仅图标运动，卡片、底块和文字保持稳定。电脑鼠标进入整张可用卡片播放一次；手机、笔触在有效 click 后播放；键盘 Enter 激活亦播放。原生链接不等待动画，离开页面会取消剩余帧。
占位入口没有链接、额外焦点或点击动画；后续成为可用链接后，工作台内部的事件委托会自动响应。未知服务 key 使用 320ms、1.1 倍轻放大的通用反馈。

| 入口 | 峰值动作 | 时长 |
| --- | --- | --- |
| 课程资源 | 转动 −8°、放大 1.12 倍 | 360ms |
| 资料库 | 上移 3px、纵向放大 1.1 倍 | 360ms |
| 课程专区 | 上移 4px、转动 5° | 380ms |
| 求职实习 | 转动 −7° 后回摆 4° | 380ms |
| 简历工具 | 上移 4px、转动 −4° | 320ms |
| 校园服务 | 上移 2px、放大 1.1 倍 | 360ms |
| 学生认证 | 转动 5°、放大 1.08 倍 | 340ms |
| 校友网络 | 放大 1.14 倍 | 320ms |
| 商城 | 依次摆动 −10°、7°、−3° | 400ms |
| 组队 | 左右各轻移 3px | 320ms |

所有动作自动复位；鼠标中途移出以 120ms 复位，快速触发取消上一动画。减少动态效果、页面隐藏或失焦时停止。组件卸载会通过 AbortController 清理监听、取消动画并移除专用图标副本。
商城原 Font Awesome 7.3.1 路径把手到达 y=−32，原视口从 y=0 开始。本实现仅复制工作台使用的 symbol，视口改为 `-16 -48 480 544`，四边留 16 单位余量；共享 symbol、其他页面与依赖包保持。专用 symbol 使用组件模块内计数器生成标识，不依赖未导出的 Ember 内部模块。
共享图标精灵晚于工作台挂载时，临时 MutationObserver 等待原 symbol；修复完成或组件卸载即断开。首次加载、离开后返回和等待期间卸载均有真实客户端检查。
