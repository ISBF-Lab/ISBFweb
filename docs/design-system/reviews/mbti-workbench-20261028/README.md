## 人工确认与来源

用户于本聊天明确批准《工作台 MBTI 专区》实施方案：28/40/93题、默认40题、每屏一题且手动切题、私人历史及本设备续答。此次确认覆盖新专区的入口、逐题表单、结果比例、历史列表和加载/失败状态；实际视觉验收与生产发布另行记录，不因代码可渲染视为已验收。

工作台基线为 ISBFweb `9ca49588e44c18957733311239a0f355314a2980` 的 `themes/isbf-campus-feed`，入口沿用 2026-10-24 A08/C02 传统/玻璃双布局及已有默认配色。MBTI 放在现有入口末尾；未满行仍左对齐，现有导航、更多菜单、业务条件和配色设置不改。

- `/isbf/mbti` 复用共享左侧及手机底部导航，工作台保持选中；桌面不增加最近讨论栏。

## 状态与隐私边界

草稿使用原生 key-value-store 的 `discourse_` 命名空间，按账号、题量、题库版本识别；保存失败保持表单和提交标识。成功/放弃移除当前版本草稿；原生退出清理及账号切换清理防止其他账号恢复答案。私人结果及计分由插件负责；主题不将答案写入公开资料或分析事件。
