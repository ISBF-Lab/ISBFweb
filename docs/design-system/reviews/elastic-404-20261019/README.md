# 弹性404与隐藏弹球

2026-10-19，用户选择独立品牌页、弹性数字、拖开中间0后显示的隐藏按钮及极简弹球；随后明确采用最长存活时间和当前浏览器最佳记录，并授权验证完成后直接上线。

本次仅确认404的局部组合：A01的品牌与共享语义变量、C01的强调色和胶囊按钮，结合用户选定的[弹性数字交互参考](https://rickcreates.com/r/2026-09-19-boc-studio)。巨型数字、隐藏入口及游戏边界为本次新增设计，不扩展为全站空态标准。实际生产浅深色板与媒体条件保存在[来源](palette-source.json)。

直接访问由服务端模板提供基础内容及独立ES模块；站内未知路由由主题初始化器在渲染后挂载同一模块，退出时清理。普通404使用新页面；403、自定义权限说明与群组申请保持原模板。HTTP404、片段接口200、登录要求和永久链接处理保持原有语义。

鼠标或触摸横向拖开0会露出播放按钮，键盘聚焦0后可按Enter或空格发现。点击播放后仍需主动开始游戏。固定速度、归一化坐标与连续小步碰撞保持两端规则一致；球落出底部结束。后台、失焦、长帧和区域尺寸变化会暂停，手动继续后才重新计时。计时使用单调时钟，显示十分之一秒；结算或主动退出时保存更长的记录，存储被禁用时保留会话记录。减少动态效果时关闭非必要弹性，彩蛋仍可使用。
