# 本轮测试资源约束

2026-10-12用户重启服务器后，要求控制内存并停止生产排查。
主机总内存约3.6GiB；原预览容器上限2GiB不适合与生产和开发服务同时运行。
这解释需要降低本任务预算，不构成对宕机根因的确认。

- 本任务完整论坛容器 `isbf_frontend_preview_20261012` 保持停止，不重启它。
- 不停止、重启或调整生产和其他开发者服务；不继续生产健康/日志排查。
- 文档、工作树、快照和脚本存放持久目录，不把/tmp作为唯一保存位置。
- 使用本地静态预览；只允许一个限额工具容器，512MiB内存、0.5 CPU、192进程/线程上限。
- 限额容器无外网、无生产数据或Docker socket挂载，浏览器单实例、单页面、串行截图。
- 启动前主机可用内存至少1GiB；不足则不启动。运行中跌破512MiB或出现OOM即停止本任务工具。
- 退出时关闭浏览器和工具容器；不得累积孤立标签页、Rails实例或后台测试进程。
- 源码审计使用逐文件摘要或流式报告，不在内存保存完整依赖目录的重复清单。
- 避免并行编译、复制整个node_modules、无必要的完整插件副本和使用/tmp tmpfs保存大归档。

这些是运行预算，不是新的视觉token。完整业务回归须在预算允许的隔离环境开展，
离线原型的检查结果不能代替FormKit、权限、排序、分页、保存或提醒测试。
