## 缺陷与改动

GLTFLoader 在 Chromium/Firefox 中使用 ImageBitmapLoader，通过 `fetch(blob:...)` 读取
GLB 内嵌纹理；所用 Three.js 版本在 Safari 中选择图片加载器。原策略已允许
`img-src blob:`，但 `connect-src` 只有 `'self'`，使位图路径失败，材质缺少纹理。
招募文档现增加 `connect-src 'self' blob:`，其他来源限制保持。
该策略只作用于招募页，不增加跨站连接或脚本执行权限。

实际匿名论坛客户端把 `/join/` 识别为 `unknown`，已在浏览器中读到该结果。
新增公开客户端路由及其桥接：被论坛接管的 `/join`、`/join/` 在进入页面前中断客户端
transition，再完整加载同源 `/join/` 文档。原菜单继续当前窗口硬跳转，结构和外观保持。
真实已安装 App 的最终行为仍需在设备上确认；浏览器模拟 standalone 标记不替代真机验收。
