# 首页、话题与站内通知的姓名显示

2026-10-13 18:08:56（UTC+8）已增量更新活动主题 ID 4。用户确认范围为首页、普通话题的主帖与回复、站内通知列表和通知菜单；邮件、推送及其他页面的名称优先级不在本次范围。最终视觉验收由用户完成，当前待确认。

首页原本直接使用 `creator.name || creator.username`。话题作者采用核心名称优先级，生产的 `prioritize_username_in_ux` 为 true，主题又隐藏第二名称，因此主标签仍显示用户名。分组通知另受 `prioritize_full_name_in_ux` 控制，该值为 false。此次保留这些全站设置，只统一指定区域的显示规则。

## 实现与来源

- 共用 `user-display` 根据已序列化的姓名显示作者；空值和纯空格姓名回退用户名。有姓名的通知发起人显示“姓名 + @用户名”，无姓名时只显示用户名。
- `isbf-user-display` 通过现有 `api.modifyClass` 类扩展接口修改核心作者与菜单组件的 getter。作者扩展受现有 `isFeedStylePost` 条件限制；菜单扩展仅处理 `UserMenuNotificationItem`，其他菜单条目继续使用原 getter。
- 保留原生作者链接、身份标记、通知点击及已读处理。多人点赞、表情回应、移动帖子、群组提及保留人数、动作和群组语义；系统文案及没有单一发起人的回复汇总保持原文。姓名字段按原生模板转义，不生成 HTML。
- 复用 A02/A04/A05、C09/C13 的现有组件及文字区域，没有新增样式或视觉 token，不扩大 Approved 范围。

发布前保存了完整活动主题及核心/插件摘要。首页字段 227 的生产版本还包含首页置顶及官方活动校区参数，工作区旧版没有这些增量。实际发布源码基于生产版本只添加名称 helper 导入和替换作者 getter，其他字节保留；不能用工作区整份主题覆盖生产。

本次修改字段 227、236，新增运行字段 406、407 和测试字段 408、409；主题从 169 字段增至 173 字段，原有另外 167 字段和主题设置、色板、组件关系、全站姓名设置保持。核心仍为 `132cc95d043db01251eedf9c93b3927cd5ffee91`；全部 63 插件的源码、隐藏文件、链接和共享发布标记在更新前后完全一致。未重建镜像、重启服务、提交用户偏好或执行数据库迁移。

`sources/` 保存六份实际发布源码的非执行副本，版本与 SHA-256 见 [manifest.json](manifest.json)。其中首页副本保留生产已有增量；它是运行来源证据，不是整份可安装主题。

## 用户验收与回退

保存姓名后刷新[首页](https://isbf-one.com/)、任一普通话题和[自己的通知页](https://isbf-one.com/my/notifications)，在桌面和手机确认作者显示姓名与 `@用户名`，收到的用户通知采用相同显示方式；无姓名时回退用户名。作者与通知原有链接应仍可打开。

私有备份、候选、检查日志、完整性报告和发布脚本位于 `deploy-work/user-display-20261013/`。定向回退命令为 `python3 deploy-work/user-display-20261013/release.py rollback`，先确认六个相关字段仍匹配本次发布摘要；回退恢复两个原组件并移除本次新增字段，不覆盖其他字段、插件或用户数据。若相关字段已有后续编辑，脚本会拒绝覆盖，需按当前版本合并。
