## 备份与定向回退

`theme-before.json` 保存部署前全部主题字段及设置，`payload.json` 保存八项增量，

不将数据库备份、用户截图或临时验收凭据提交到 Git。

必要时运行同目录的 `release.py rollback`。回退脚本先确认八项仍为此次发布的摘要，
仅恢复两项原值、删除此次新增的六项，并重新编译主题；不恢复整个数据库。
若其他开发者已修改这些字段，应先合并对应变化，不强制覆盖。
