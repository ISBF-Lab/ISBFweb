# 头像框格式规范与上传校准方案

状态：**已实现，用户已验收**。用户于 2026-10-11 以“开始实现”确认下述制作模板、上传校准布局与统一定位规则。确认范围只限头像框校准区域和定位修复，不包含后台其他表单的视觉批准。后续用户明确“你不需要校准这两个 我自己来”，因此现有「种子用户」和 EVA02 的定位参数由用户自行调整；发布只上线校准工具。实际发布源码为 `bbdabecf040bdbb6d5bb3f88d6e748738ddf7a41`，证据见[校准发布记录](../../avatar-frame-calibration-production-20261011.md)。

## 要解决的问题

288×288 正方形只说明图片画布，不说明装饰圆环的圆心与头像所在区域。实际「种子用户」素材的圆环向下偏约 8px；EVA02 的圆心基本正常，但设置预览继承了 3px 外边距，个人主页又把 4px 白边计入框的缩放。单独强化文件格式要求无法解决后两项页面几何问题。

排查依据：[实际素材、源码与局部复现](../../avatar-frame-alignment-20261011.md)。提案前的上传实现位于 `plugins/discourse-avatar-frames/lib/discourse_avatar_frames/png.rb`、`upload_creator.rb` 和 `admin/.../components/avatar-frame-upload.gjs`，保留动画原图并生成静态版本，没有校准步骤。

## 推荐设计

### 1. 提供明确的制作坐标

- 正方形透明 PNG/APNG，继续使用 `.png` 后缀和现有站点文件大小、像素限制。
- 标准制作画布为 288×288，头像定位参考圆的中心为 `(144, 144)`、直径为 `240px`；更高分辨率按比例制作。参考圆表示头像图像区域，不包含个人主页的白边。
- 图像背景与主要头像区域透明；装饰可向圆内少量延伸，不要求素材必须包含完整闭合圆环。完全不透明的图片应在上传时拒收。
- 动画在整个播放过程中使用固定的头像圆心和定位区域，允许装饰、颜色、光效变化。此要求指逻辑画布及完整合成画面，不禁止 APNG 使用不同大小的增量帧。
- [制作参考 SVG](../../downloads/avatar-frame-guide.svg) 中的 `guides` 是辅助线，导出前隐藏或删除；用户提供的装饰放在 `artwork` 组。辅助线不能导出进成品。

制作规范是默认定位约定，不假定系统可以从任意 PNG 中可靠识别作者的头像区域。

### 2. 上传后校准，定位数据随款式保存

建议流程为 **上传 → 叠加头像预览 → 必要时校准 → 确认并保存**。

- 在已有头像框上传字段内增加校准区域，展示示例圆形头像与实际素材的叠加效果，不再只展示孤立的框图片。
- 已确认布局：在原有上传字段位置先放叠加预览，显示 144px 和 48px 两种头像效果；下方按单列依次放三个调节项与恢复默认操作，手机同样竖排。预览使用已有头像与叠层组件，不裁切溢出的装饰。该布局及控件外观属于本次明确确认范围，不扩展到后台其他表单。
- 标准素材默认采用现有 120% 大小、居中位置；一般只需看过预览后确认。
- 提供「大小」「左右位置」「上下位置」三个调节项，以及恢复默认位置的操作。数值来自明确的头像几何关系，不把它们推广成全站颜色、间距或尺寸 token。
- 服务器为每款框保存统一的大小和偏移参数；所有参数按头像图像尺寸归一化。替换图片后重新校准，动态版本和静态版本使用同一组参数。
- 自动圆环识别作为辅助：对可靠闭合圆环给出建议位置，复杂或非闭合装饰进入人工校准。不得按整个非透明像素的外接框自动居中——顶部嫩芽和侧边挂件会使外接框偏移。
- 保留原始 PNG/APNG。优先改变渲染定位数据，避免为了重新居中而裁掉顶部装饰、反复重采样像素画，或重编码动画。
- 新上传或替换图片的款式，确认校准后才能发布供用户选择。现有款式与授予记录保留；「种子用户」和 EVA02 由用户自行校准，发布不写入这两款的测量建议。

内部可以用头像参考圆的归一化中心与直径表示定位，再换算成渲染大小和偏移。这些坐标属于开发接口，不要求管理员填写 JSON 或理解圆心算法。若参考圆中心为 `(cx, cy)`、直径为 `d`（均以画布尺寸归一化），头像图像直径为 `A`，则图片显示边长为 `A/d`，图片左上角相对头像左上角为 `A × (0.5-cx/d, 0.5-cy/d)`。默认 `cx=cy=0.5`、`d=5/6` 正好对应现有 120% 大小与 -10% inset。

### 3. 所有场景采用相同头像几何基准

- 设置预览、个人主页、帖子和主题头像挂载点复用同一套锚点与定位计算；预览中确认的位置就是佩戴位置。
- 锚点基于头像图像区域，排版外边距和个人主页白边放在外围，不能改变框的圆心或比例。
- 保留个人主页已批准的头像尺寸与 4px 白边。新增逻辑不靠移除白边或放大所有头像来获得贴合效果。
- 保留圆形头像、完整装饰、不拦截点击、减少动画偏好和现有 flair 层级；不对父容器增加会裁掉框的 `overflow: hidden`。
- 缩小尺寸时只按相同参数等比缩放，不对每个路由增加独立的像素补丁。

## 设计来源与复用边界

| 区域 | 可复用来源 | 边界 |
| --- | --- | --- |
| 公开资料头像 | A11、C03，主题 common 中的资料头像规则 | 保留头像尺寸、圆形、白边与页面布局 |
| 头像框叠层 | A14、C03，现有 `avatar-frame-overlay.gjs` 与 `avatar-frames.scss` | 复用装饰层、静态/动画选择、点击与 flair 行为；新定位参数由本次方案确认 |
| 后台上传字段 | 现有头像框表单的权限、上传与保存行为；FormKit/UI kit 的工程 API | 现有后台外观没有整体 Approved 参考，不能由 A14 推导新校准控件的视觉规则 |

提案不新增品牌色、字体或页面壳，不重设计授予、CSV 导入、个人设置表单或后台导航。

## 已确认的实施范围

1. 采用「制作模板 + 上传校准 + 保留原图」方案，允许导入布局不同的素材。
2. 以头像图像区域为统一基准，保留个人主页原有白边，将其排除在框的缩放计算之外。
3. 后台校准区采用「144px/48px 叠加预览在上、三项调节与恢复默认单列在下，手机同样竖排」。用户已确认此新增区域；不将其扩展为通用后台设计。

如果仅要求所有作者严格遵循固定模板，可以省去校准区；但不能可靠接收已有布局不同的素材，仍必须修复统一锚点与预览样式。自动修改图片作为替代方案会增加动画处理与裁切风险，因此本提案优先保存定位数据。

## 实施时的必要验证

仅检查实际变更涉及的上传校准、保存参数和统一定位。两款真实素材只作为隔离预览库的验证样本，不写入生产参数。上传格式与定位参数必须服务端校验；不重复执行与头像框定位无关的完整业务验收。若发布生产，仍遵守项目规定的插件库存、主题保留与部署完整性检查。
