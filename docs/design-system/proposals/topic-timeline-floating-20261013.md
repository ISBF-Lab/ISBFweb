## 确认的局部规则

所有尺寸默认收起，有可用阅读进度时显示顶部入口。展开后固定于视窗右侧，正文和现有右栏不移动。

| 属性 | 本轮规则 |
| --- | --- |
| 横向顺序 | 日期、当前楼层和阅读信息在左，文字朝轨道对齐；纵向轨道及滑块在右 |
| 宽度 | 按内容收窄，受视窗和安全区约束，不使用340px右栏宽度 |
| 外形 | 12px内距、8px操作间距、现有1px边框、16px圆角 |
| 毛玻璃 | 60% `--isbf-v2-background`与透明混合，24px背景模糊；跟随明暗语义配色 |
| 位置 | 标题栏下方12px、右侧12px并计入安全区；手机保留底部130px及安全区 |
| 时间轴 | 沿用4px轨道、16px圆形滑块及Core的50px纵向滑块区域和计算 |
| 触控 | 手机关闭和操作按钮最小44px；浮层可纵向滚动，原生轨道拖动保留 |
| 返回 | 固定于底部操作行，与跳转及通知对齐，使用现有按钮配色和8px间距；沿用原生阅读距离阈值和过滤后的楼层索引，不悬在轨道中段 |

顶部按钮、关闭按钮、外部点击和Esc收起。显式关闭恢复入口焦点，外部点击保留目标焦点。子菜单及跳转弹窗使用原生交互，Esc优先交给当前子浮层。
