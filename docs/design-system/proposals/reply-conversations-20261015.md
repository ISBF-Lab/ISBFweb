## 确认的行为

- 主帖不计讨论组；直接回复主帖或无回复对象的发言为根讨论。
- 组内任意深度统一一层缩进，主竖线由根回复头像底部延伸，直线短支线连接子回复头像中心；按原始回复关系显示“回复某人 · #楼层”。
- 默认最早三条预览；展开后每页50条，收起恢复三条；外层每页20组。
- 点击回复对象就地加载原文预览，保留原文链接；不可查看时不暴露正文。
- 查看对话与写回复分开，发布新回复自动展开所属组并定位新内容。
- 页头和时间轴只显示简洁的“当前 / 总数”（如“1 / 2”），不附分组说明和总回复数；通知和旧链接自动展开目标组。
- 仅复用现有语义token；使用UI kit、原生编辑器与权限；文案可翻译。
