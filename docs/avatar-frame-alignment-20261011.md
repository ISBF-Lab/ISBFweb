# 头像框对齐排查：种子用户与 EVA02-Gin

2026-10-11，针对生产目录中 ID 10「种子用户」和 ID 9「EVA02-Gin」进行排查。两款均为后台上传的 288×288 PNG/APNG，不是插件内置框；这里的「种子用户」是头像框名称，不是用户账号。

## 已定位的问题

1. **设置预览存在确定的 3px 横向错位。** Core 的 `app/assets/stylesheets/common/base/user.scss` 在 `.user-preferences .avatar` 上设置 `margin-left: 3px`。插件的 `.avatar-frame-preferences__preview > img` 没有重置外边距；头像因此右移，绝对定位的框仍围绕 48px 容器居中。两款框都受影响。在浏览器局部复现中，框与头像图片的中心差为 `(-3, 0)`；仅在复现页重置头像外边距后变为 `(0, 0)`。
2. **「种子用户」素材的圆环中心与画布中心不同。** 画布中心是 `(144, 144)`。对静态图圆环内沿的透明边界拟合，中心约为 `(144.12, 152.16)`，内径约 `237.15px`，拟合误差约 `0.30px`。圆环在画布内向下偏约 `8.16px`。现有 overlay 按整张画布居中、放大到头像容器的 120%，不会识别圆环中心。48px 预览的圆环下偏约 `1.63px`；144px 头像加两侧 4px 边框的个人主页复现中，下偏约 `5.16px`。
3. **EVA02-Gin 静态素材圆心基本正确；个人主页的白边影响视觉贴合。** 同样拟合得到中心约 `(143.86, 143.19)`，内径约 `239.74px`。该素材没有「种子用户」那种明显的圆心下移。生产主题为个人主页头像设置 `4px solid` 边框；桌面 144px 头像的外盒因此为 152px，框按这个外盒放大到约 182.4px。圆环内径于是约为 151.8px，接近含白边的尺寸，而不是 144px 的头像图像区域。这会留下约 4px 的视觉间隙，不能与中心位移混为一谈。

## 修复边界与建议

- 将预览头像与框绑定在相同几何锚点，局部重置预览头像的外边距；不修改全局 `.user-preferences .avatar`，也不重设计设置表单。
- 个人主页应明确框的内圈对齐头像图像区域还是含白边外盒，再统一预览与实际佩戴的计算方式。保留 A11 已批准的头像尺寸、边框、圆形和页面布局，不能为修复间隙直接移除已批准的白边。
- 「种子用户」需要独立的圆心校准，不能对所有头像框统一上移。不要把上传名称或记录 UUID 写成 CSS 特例。若要增加每款框的缩放/偏移参数，应先提交其存储方式及管理操作设计供确认；当前 A14 的 120% 基线不自动批准新校准规则或后台控件。
- 本次仅定位原因和记录建议，未发布页面或素材修改；复现中外边距清除只作用于诊断页面。设计参考来源为 `docs/design-system/ui-status.md` 中的 A11/A14 及 `components.md` 中的 C03，新的规则尚未获得视觉批准。
