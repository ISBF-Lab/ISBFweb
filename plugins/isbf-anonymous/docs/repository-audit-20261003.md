## 尚未完成的运行时验证

本审查环境没有原生 Ruby、Bundler、PostgreSQL 或 Redis，也没有运行中的 Discourse 测试服务。
已尝试仓库要求的 `bin/lint --fix`、RSpec 和主题 QUnit 命令，均无法启动所需的 Ruby 环境。
因此 Ruby 格式/RuboCop、RSpec、浏览器 QUnit、数据库迁移和完整打包仍需在开发环境运行；本 PR 保留为草稿。

主题文档要求的 `isbf-calendar` 插件不在本仓库。
`/isbf/calendar`、`/isbf/workbench` 和个人日历 API 的服务端实现需要单独补齐，才能复现完整站点和检验授权及持久化行为。
本次没有根据前端接口猜测并新增这个插件。

开发环境中的验证命令：

```sh
LOAD_PLUGINS=1 bin/rspec plugins/isbf-anonymous/spec
bin/rspec spec/mailers/user_notifications_spec.rb -e "invitation email titles"
bin/qunit --target isbf-anonymous
bin/qunit --theme-name "ISBF Campus Feed" --qunit-path /theme-qunit --filter "ISBF Campus Feed"
bin/lint --fix --recent
```

运行主题测试前，应导入本分支的 `themes/isbf-campus-feed`，选择正确的主题 ID。
主题组件测试模拟 HTTP；检查真实日历流程时，还需提供上述日历插件。
合并前还应重跑核心发布测试，确认普通身份、主题作者、管理员及分类群组管理员原有的回复行为。
