# 真实简历分享

2026-10-14 用户确认。简历专区 `/isbf/workbench/resume` 先显示“真实简历分享”和“个人简历生成”。原有生成器通过 `/isbf/workbench/resume/generate` 使用原组件和原接口。分享列表 `/isbf/workbench/resume/shares` 展示已通过审核的标题、描述和可选背景信息，右上角提供上传入口。

## 提交与查看

已登录、未封禁和未禁言的用户可以选择一个 PDF 并确认无偿分享。标题、行业、岗位、薪资、工作年限和描述均可留空；标题留空时使用文件名。页面鼓励提供背景信息，并提醒先移除不想公开的个人信息。

服务端限制 10 MiB、100 页，校验文件扩展名、PDF 签名和真实结构，拒绝损坏或加密的 PDF。Python 使用 `requirements.txt` 已锁定的 pypdf，本地 Poppler `pdftoppm` 生成逐页 PNG；不通过外部服务预览或存储。

提交后状态为待审核。列表只展示已通过审核的记录；未通过审核时，详情、PDF 和 PNG 仅允许上传者或具备本功能审核权限的人访问。公开详情显示审核后的描述，原提交描述和审核历史仅在私有详情中提供。下载保留上传的原 PDF 字节。

## 审核与权限

`discourse-academy-roles` 的管理员权限面板新增 `review_resumes`，对应站点设置 `academy_moderators_review_resumes`，默认关闭。本站“开发者”对应原生 `admin`，“管理员”对应原生 `moderator`。关闭时仅开发者审核；打开后允许管理员审核。每次审核均在服务端重新检查实际角色及当前设置。

审核通过必须提供非空简要描述。审核人可以沿用或修改上传者的描述，也可以拒绝申请。一次审核原子保存最终状态、最终描述、审核账号 ID、用户名、姓名快照、原提交描述、前一描述及时间。账号改名后保留当时的快照；乐观版本号和行锁阻止重复审核覆盖已完成决定。

## 存储、迁移与恢复

分享文件独立保存在 `ISBF_RESUME_SHARING_STORAGE_PATH`，默认 `/shared/isbf-resume-shares-private`。该目录必须持久化且不能位于公共静态上传路径。目录权限 700、文件 600；生成器原有私有目录独立保留。生产配置必须为分享目录安排持久挂载、属主和同数据库同步的备份，默认论坛上传备份不代表包含此目录。

新插件迁移增加 `isbf_resume_shared_resumes` 与 `isbf_resume_share_reviews`，不修改旧表。通过正常插件迁移执行。迁移支持逆向结构回滚，但有实际分享或审核记录后应保留表和文件，通过恢复主题入口及向前修复代码处理故障，不能以删表或删除申请代替代码回滚。

主题仅扩大当前运行版 `isbf-v2-shell.gjs` 的简历子路由识别条件。补丁与现场字段摘要在主题仓库 `docs/RESUME_SHARING_ROUTES.md` 中；合并时将这一条件增量整合进最新主题，保留其他导航、组件、样式和设置更新。

## 验证与发布

RSpec 覆盖真实解析/渲染、提交、审核、权限切换、文件访问及审核留痕。QUnit 使用实际 FormKit 验证入口、分页、上传、审核表单和详情。测试使用任务独立 PostgreSQL、Redis 和私有文件目录。

上线前须提供同一候选的真实交互页面供用户验收，取得本版本明确部署确认，再备份当前将更新的插件、权限配置、主题字段及私有数据。静态提案和代码审阅不构成功能验收或生产部署授权。
