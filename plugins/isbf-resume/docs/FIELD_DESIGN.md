# 简历采集字段与填写说明

全局必填项只有姓名、联系电话和电子邮箱。所有说明在输入后仍应显示；示例作为额外 placeholder，不代替填写说明。

其他模块全部选填。用户添加一条非空经历时，需要填写对应学校、单位、项目或条目名称；未填写的空记录不导出。

## 基本信息

姓名、联系电话和电子邮箱必填；其余信息按应聘岗位需要填写，未填写的项目不会出现在简历中。

| 填写项 | 必填规则 | 填写说明 | 示例 |
| --- | --- | --- | --- |
| 姓名 | 必填 | 填写投递简历使用的真实姓名；海外申请可按需要填写英文姓名。 | 例如：张明 |
| 联系电话 | 必填 | 填写能联系到你的常用号码。投递海外岗位建议加区号。 | 例如：+86 138 0000 0000 |
| 电子邮箱 | 必填 | 推荐学校邮箱/专业稳定的商业邮箱；确认拼写正确，并能正常收信。 | 例如：name@example.com |
| 求职意向 | 选填 | 明确具体岗位，避免写“意向广泛”；可填写岗位名称及方向。 | 例如：前端开发工程师 |
| 现居城市 | 选填 | 填写目前居住的城市；跨国投递可加国家或地区，无需填写详细住址。 | 例如：北京 / Singapore |
| 期望城市 | 选填 | 填写希望工作的城市；多个城市可用顿号分隔，接受远程工作时也可注明。 | 例如：北京、上海、远程 |
| 证件照 | 选填 | 按岗位及投递要求上传清晰的本人证件照；支持 JPG、PNG、WebP，最大 5 MB，不上传时不保留照片空位。 |  |
| 出生年月 | 选填 | 按岗位需要填写出生年份和月份，不需要填写具体日期。 | 例如：2002-08 |
| 最高学历与院校 | 选填 | 建议按“院校·专业·学历”填写；详细教育经历可在下方单独补充。 | 例如：清华大学·计算机科学与技术·本科 |
| 政治面貌 | 选填 | 按实际情况填写，如中共党员、中共预备党员、共青团员或群众等。 | 例如：共青团员 |
| 籍贯 | 选填 | 通常精确到省市即可，按岗位需要填写。 | 例如：浙江杭州 |
| 民族 | 选填 | 按实际情况填写民族名称；没有投递要求时可留空。 | 例如：汉族 |
| 技术社区 / 作品主页 | 选填 | 适用于互联网、技术、设计岗位。填写 GitHub、个人博客、Behance、作品集网盘或直链；每行一条，可注明平台名称。 | GitHub：https://github.com/your-name<br>作品集：https://example.com/portfolio |
| LinkedIn 个人主页 | 选填 | 外企或海外申请可填写个人职业社交档案的完整直链；请填写个人主页地址。 | https://www.linkedin.com/in/your-name/ |
| 签证 / 许可状态 | 选填 | 涉及跨国应聘时，填写当前实际工作许可类型或雇主担保需求，如 OPT、Green Card、无需雇主担保等。 | 例如：OPT / 无需雇主担保 |
| 身高 | 选填 | 按岗位要求填写身高并注明单位，没有相关要求时可留空。 | 例如：175 cm |
| 体重 | 选填 | 按岗位要求填写体重并注明单位，没有相关要求时可留空。 | 例如：65 kg |
| 视力 | 选填 | 仅在岗位有要求时填写；注明左右眼，以及裸眼或矫正视力，按实际资料填写。 | 例如：矫正视力，左眼 1.0、右眼 1.0 |
| 外语等级 | 选填 | 填写已经取得的外语等级或考试成绩，如托业、专八；更详细的语言能力可在技能与证书中补充。 | 例如：TOEIC 900 / 英语专业八级 |

## 教育背景

按最近经历在前的顺序填写，可添加多段教育经历。整个模块选填；填写一条经历时需注明学校。

| 填写项 | 必填规则 | 填写说明 | 示例 |
| --- | --- | --- | --- |
| 学校名称 | 填写该条经历时必填 | 填写学校全称或通用名称；交换、联合培养经历可分别添加。 | 例如：清华大学 |
| 专业 | 选填 | 填写专业或研究方向；辅修可直接补充在本栏。 | 例如：计算机科学与技术 |
| 学历 / 学位 | 选填 | 填写已取得或正在攻读的学历、学位；未毕业时可注明在读。 | 例如：本科 / 硕士在读 |
| 开始年月 | 选填 | 填写入学年月，只需精确到月。 | 例如：2022-09 |
| 结束 / 预计毕业年月 | 选填 | 填写毕业或预计毕业年月；在读且尚未确定毕业时间时可留空，并勾选下方“在读”。 | 例如：2026-06 |
| 在读 | 选填 | 目前仍在就读时勾选；未填写结束年月时，时间栏会显示“至今”。 |  |
| 相关课程 | 选填 | 选择与目标岗位相关的课程，用顿号或逗号分隔；不必罗列全部课程。 | 例如：数据结构、数据库系统、软件工程 |
| 成绩与教育补充 | 选填 | 可填写 GPA（注明满分）、排名、交换经历或毕业论文方向；按实际资料填写，每行一个要点。 | GPA：3.8/4.0<br>毕业论文：…… |

## 工作与实习经历

正式工作和实习放在同一模块，按最近经历在前的顺序填写。没有相关经历时可跳过。

| 填写项 | 必填规则 | 填写说明 | 示例 |
| --- | --- | --- | --- |
| 单位名称 | 填写该条经历时必填 | 填写公司或机构名称；填写了经历内容时，需要注明所属单位。 | 例如：某某科技有限公司 |
| 岗位名称 | 选填 | 填写实际岗位名称，可注明实习生、兼职等身份。 | 例如：前端开发实习生 |
| 部门 / 业务方向 | 选填 | 可填写所属部门、产品线或业务方向，帮助读者理解工作背景。 | 例如：研发部 · 企业服务产品 |
| 开始年月 | 选填 | 填写入职或实习开始年月。 | 例如：2025-03 |
| 结束年月 | 选填 | 填写离职或实习结束年月；仍在职时可留空，并勾选下方“在职”。 | 例如：2025-08 |
| 在职 | 选填 | 目前仍在该单位工作时勾选，时间栏显示“至今”。 |  |
| 职责与成果 | 选填 | 每行一个要点，说明你承担的工作、采用的方法及实际成果；有数据时注明指标和范围，不虚构数字。 | 负责……，使用……完成……<br>参与……，取得……成果 |

## 项目与科研经历

可填写课程项目、个人作品、团队项目或科研课题。优先选择与目标岗位相关的经历。

| 填写项 | 必填规则 | 填写说明 | 示例 |
| --- | --- | --- | --- |
| 项目 / 课题名称 | 填写该条经历时必填 | 填写能说明项目用途的名称；科研经历可填写课题名称。 | 例如：校园活动管理系统 |
| 个人角色 | 选填 | 说明你在项目中的实际职责，区分独立完成、负责人或团队成员。 | 例如：前端开发 / 项目负责人 |
| 开始年月 | 选填 | 填写项目或课题开始年月。 | 例如：2024-10 |
| 结束年月 | 选填 | 填写完成年月；尚在进行时可留空，并勾选下方“进行中”。 | 例如：2025-02 |
| 进行中 | 选填 | 目前仍在开展该项目或课题时勾选，时间栏显示“至今”。 |  |
| 技术 / 方法 | 选填 | 列出你实际使用的技术、工具、设计方法或研究方法。 | 例如：Vue、Python、用户访谈 |
| 项目 / 论文链接 | 选填 | 填写可访问的完整链接，如代码仓库、作品展示、论文或项目演示；不填写内部或无权公开的资料。 | https://example.com/project |
| 项目内容与个人贡献 | 选填 | 每行一个要点，写清项目目标、你完成的部分和结果；团队成果与个人贡献应区分说明。 | 项目用于……<br>我负责……，完成…… |

## 校园与实践经历

可填写学生组织、社团、志愿服务、社会实践或活动运营经历。没有相关内容时可跳过。

| 填写项 | 必填规则 | 填写说明 | 示例 |
| --- | --- | --- | --- |
| 组织 / 活动名称 | 填写该条经历时必填 | 填写所属组织或参与活动的名称。 | 例如：计算机协会 / 校园开放日 |
| 担任角色 | 选填 | 填写实际担任的职务或参与身份。 | 例如：活动负责人 / 志愿者 |
| 开始年月 | 选填 | 填写参与该组织或活动的开始年月。 | 例如：2023-09 |
| 结束年月 | 选填 | 填写结束年月；仍在参与时可留空，并勾选下方“进行中”。 | 例如：2024-06 |
| 进行中 | 选填 | 目前仍在参与时勾选，时间栏显示“至今”。 |  |
| 职责与成果 | 选填 | 每行一个要点，说明组织协调、运营或服务工作，以及实际覆盖人数、活动规模或产出。 | 组织……活动，负责……<br>协助……，完成…… |

## 技能与证书

可填写专业技能、语言能力和资格证书，优先填写与目标岗位相关且能够说明水平的内容。

| 填写项 | 必填规则 | 填写说明 | 示例 |
| --- | --- | --- | --- |
| 技能 / 证书名称 | 填写该条经历时必填 | 填写具体技能或已取得的证书名称。 | 例如：Python / IELTS / 教师资格证 |
| 掌握程度 / 等级 / 成绩 | 选填 | 填写实际熟练程度、证书等级或考试成绩，避免仅写“精通”而没有依据。 | 例如：可独立进行数据清洗 / IELTS 7.0 |
| 取得年月 | 选填 | 证书或成绩可填写取得年月；一般技能可留空。 | 例如：2025-05 |
| 发证机构 | 选填 | 证书可填写发证或认证机构；一般技能可留空。 | 例如：教育部教育考试院 |
| 使用场景 / 有效期补充 | 选填 | 可补充实际使用场景、相关作品，或成绩和证书的有效期；每行一个要点。 | 在……项目中用于……<br>有效期至…… |

## 荣誉与奖项

可填写竞赛奖项、奖学金或与岗位相关的荣誉。没有相关内容时可跳过。

| 填写项 | 必填规则 | 填写说明 | 示例 |
| --- | --- | --- | --- |
| 奖项 / 荣誉名称 | 填写该条经历时必填 | 填写奖项名称及获奖等级，必要时注明国家级、省级或校级。 | 例如：某某竞赛省级一等奖 |
| 获得年月 | 选填 | 填写获得该奖项或荣誉的年月。 | 例如：2024-11 |
| 授予机构 | 选填 | 填写主办或授予机构，帮助说明奖项来源。 | 例如：某某大学 / 竞赛组委会 |
| 奖项补充说明 | 选填 | 可说明评选范围、获奖作品或你在团队中的贡献，按实际资料填写。 | 获奖作品为……，本人负责…… |

## 自我评价

选填。用简短文字补充与目标岗位相关的能力或经历，已有内容充分时可以省略。

| 填写项 | 必填规则 | 填写说明 | 示例 |
| --- | --- | --- | --- |
| 自我评价 | 选填 | 建议 2–4 句，说明相关经验、能力及工作方向；避免空泛性格评价，不重复整份简历。系统会保留你的原文。 | 具备……经验，曾完成……，能够…… |
