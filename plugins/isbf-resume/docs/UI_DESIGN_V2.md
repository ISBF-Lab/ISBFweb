## R01 · 内容布局

保留站点导航，主区域采用现有工作台功能区。足够宽时，内容填写和预览并排；窄屏通过阶段切换查看预览，不把侧栏、表单与预览一起压缩。

在 1440 px 设计稿中，功能区宽 920 px，沿用左右 26 px 内距；内层可用 868 px，填写区 560 px、间距 24 px、预览区 284 px。这些是本方案的局部布局分配，不新增全局 token。字段优先按可用宽度自然排列；长文本和作品链接占整行。

先显示基本信息的姓名、联系电话、电子邮箱、求职意向、现居城市、期望城市、最高学历与院校和证件照；其余 11 项置于“更多基本信息”。没有删减用户指定字段。七个可选经历模块分别折叠展示，展开后显示完整字段与说明。

手机采用单列，沿用现有功能区的 16 px 内距、站点导航及底部安全区。阶段切换和主要动作不依赖悬停。整体正常滚动，不锁定页面高度，也不另建覆盖底栏的固定下载条。

## R02 · 输入与文字

候选局部样式：标签使用 `font-sm` / `weight-medium`，输入内容 `font-sm`，说明 `font-xs`。页面标题参考现有功能区 `h1` 的 `clamp(28px, 3vw, 34px)`；该参考仅用于本功能区，不扩展为全站标题层级。标签与说明均开始对齐，不沿用认证页的居中排版。

单行控件最小高 48 px，内距使用已有 `space-3`，圆角使用 `radius-sm`；多行内容自然增加高度。字段间距使用 `space-6`，分组使用分隔线，不给每个字段套带阴影的卡片。

说明及可操作的阶段标签使用主文本色。2026-10-12 按用户实际网页反馈，示例文字改为主文本色 65% 与 surface 35% 的局部混合色，输入文字继续用主文本色。必读说明保持主文本色，避免直接使用低对比度的明色 muted。输入边界使用 muted 色，聚焦使用既有 focus-ring 映射；规则仅作用于简历区域，不增加全站 token。长基本信息、链接以及经历中的文字字段占整行。原六张静态图仍反映初版，当前增量与验证见 [本轮改进记录](FEEDBACK_20261012.md)。

## R03 · 完整字段及说明

字段契约继续使用 `resume_schema.json`，总计 58 项。全局必填仅姓名、联系电话、电子邮箱。非空记录需填写学校、单位或条目名称；完全空白的记录和模块不导出。

每项说明用 FormKit `@helpText` 持续显示在控件下方，示例单独用 placeholder。输入、日期、勾选、照片都保留可访问标签及说明关联，不通过 tooltip 隐藏必要说明。填写框的完整文案见 [FIELD_DESIGN.md](FIELD_DESIGN.md)。

经历可以添加或移除；新增记录具有稳定标识，不以当前数组下标作为组件 key。保存和导出时保持用户顺序。删除本条使用 `DButton` 行内动作，不新增未批准的确认弹窗。

证件照通过 FormKit custom field 组合本地选图，沿用 5 MB、JPG/PNG/WebP 的限制。该照片用于简历生成，不走论坛公共附件展示；删除照片后不保留空位。

## R04 · 模板与预览

模板选择使用有名称、有选中标识的两个 radio 选项，分别展示真实蓝金和蓝灰文档缩略图。选中状态不只依靠边框颜色。两款对应已有 `blue-gold` 与 `blue-gray` 值，不另建两份字段或排版代码。

2026-10-13 根据用户实际反馈，填写页和预览阶段即时展示当前表单内容，空表单只显示填写提示；示例缩略图仅保留在模板选择处。生成完成后展示本次实际 PDF、页数和下载链接。草稿预览沿用同一文档字段顺序、文字、A4 比例和两款颜色，提示最终分页以 PDF 为准。简历纸面不随站点暗色模式改色。

输入内容或模板改变后，显示最新草稿并禁用旧版本下载，生成最新版本后才能下载。实际 PDF 超过一页时正常显示多页，不截掉正文，不自动缩小字体；草稿完整呈现正文，不声称其浏览器排版是最终 PDF 分页。

## R05 · 状态与操作

| 状态 | 候选行为与呈现 |
| --- | --- |
| 未填写 / 未生成 | 空表单显示填写提示；有内容时实时展示当前草稿，本次文件下载禁用 |
| 聚焦 | 保留标签和说明，显示可见焦点描边；键盘可操作 |
| 校验失败 | 展开所在模块并定位字段，错误文字置于该字段附近；保留全部输入 |
| 无照片 | 显示选择入口和格式说明，导出不留空白照片位 |
| 照片无效 | 就地提示格式、大小或读取问题，不清空其他字段 |
| 生成中 | 显示“正在生成…”；生成按钮暂时禁用，输入内容保留 |
| 生成成功 | 展示本次 PDF 和实际页数，两个文件分别下载 |
| 生成失败 | 显示明确失败原因和重试动作；草稿保留 |
| 内容已修改 | 实时展示当前草稿，标记旧导出失效，生成最新版本后再下载 |

输入字段与生成状态通过现有 `a11y` service 播报，不另造动态 live region。下载链接只关联当前用户拥有的生成任务。若生成时继续修改，结果必须与请求版本核对，不能把旧请求结果当成最新简历。

## R06 · 真实页面壳接入

新增简历路由后，复用当前 `ISBFV2Shell` 的工作台归属、导航及功能区；显式处理 `pageKind`、`isWorkbench`、`showPageHeader`、`showRightRail` 和正文出口。不能只添加 href，也不能复制另一套 sidebar。

接入文件和模块划分见 [SERVER_ARCHITECTURE.md](SERVER_ARCHITECTURE.md)。网页正文可由简历插件模板渲染，壳只提供已有导航；此路由不套当前工作台隐藏 `#main-outlet` 的规则。工作台网格渲染也须改为精确首页判定，不能继续复用扩大后的 `isWorkbench` 家族判定。它避免主题导入插件业务组件，以及插件关闭时导致主题找不到组件。

该新路由的桌面、窄屏、手机、明暗、未登录和插件关闭状态都需要实际开发环境验证。设计图只供确认视觉方案，不是功能验收。
