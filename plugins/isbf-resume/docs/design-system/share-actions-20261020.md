# 简历分享操作菜单

2026-10-20，用户通过线上截图确认：标题和全部操作能在同一行容纳时保留当前蓝色按钮，否则将操作收纳到三点菜单。菜单项无蓝底、纯文本居中；用户明确要求完成后直接上线，无需再次人工验收。

范围仅为简历分享列表及“我的投稿”的页头操作区。菜单沿用 C06 通知菜单的边框、surface/text、space-2/space-3、radius-sm 和现有菜单阴影；居中文本为本次明确批准的局部规则，不推广到通知或其他菜单。

工程复用 `DMenu`、`DDropdownMenu` 和 `DButton`。通过 ResizeObserver 测量标题及实际授权操作的自然宽度，在容纳不足时折叠，并在宽度恢复后展开。隐藏的测量按钮使用 inert 和 aria-hidden，避免重复聚焦；菜单保留原链接和设置操作，权限、上传、审核及生成器逻辑不变。
