# 简历分享实施依据

2026-10-14（Asia/Taipei），用户确认新增分享流程，并修正入口要求：简历专区先显示“真实简历分享”和“个人简历生成”两个选项；分享列表类似网盘，显示标题和描述，右上角提供上传按钮；详情提供预览和 PDF 下载。用户明确要求保持已有 UI 一致，个人简历生成仅多一步入口选择，不修改已有功能代码，并授权“其他没有问题 做吧”。

本次确认允许连续完成本地实现和隔离测试；不自动授权正式部署。实际交互网页仍须用户验收。

入口复用 A08/C02 工作台的入口卡片；外壳复用 A01/C04。分享列表使用现有分隔线、正文、标题和语义颜色，不引入卡片阴影或全站 token；详情和上传表单复用现行简历面板、FormKit、UI kit、间距和响应式规则。权限设置只在学号邀请码插件现有“校园功能”组增加一行。

根地址 `/isbf/workbench/resume` 改为两项选择；`/isbf/workbench/resume/generate` 直接渲染原 ResumeEditor，生成器组件、字段、照片、实时预览、导出接口和机械生成代码保持其基线。新增分享独立位于 `/isbf/workbench/resume/shares`，上传、本人投稿及审核详情均使用新组件和独立端点。

薪资、行业、岗位、年限、标题和上传描述可以留空。文件必须是 PDF；标题未填时使用文件名。通过审核时最终简要描述必填。原始描述、审核后的描述及审核者姓名/账号快照分开保存，只有审核者能查看审核记录。通过的简历面向论坛所有成员免费开放，沿用论坛本身的访问门禁。
