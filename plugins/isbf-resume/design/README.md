这些是设计提案，不是运行中的 ISBF 页面。图中的文字框和下载按钮没有提交或下载行为；集中审阅页只是图片导航。DOCX/PDF 生成核心已在上一阶段独立验证，ISBF 路由及表单仍需接入。
