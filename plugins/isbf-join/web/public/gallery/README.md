# 添加你的滚动图片

1. 把图片放在此目录，例如 `01.webp`、`02.jpg`。
2. 打开 `src/config.js`，在 `gallery.items` 中填写：

   `{ image: 'gallery/01.webp', title: '团队日常', alt: '图片内容说明' }`

3. 其余图片按相同方式填写；可以增加或减少条目。留空时显示占位框，不会请求不存在的图片。
4. 推荐横图，比例约 1.9:1，宽度 1200—1600px。文件名建议使用英文字母或数字。
5. 保存后运行 `npm run build`，刷新本地预览。`gallery.speed` 控制自动横向滚动速度（像素/秒）。

此目录中的图片会自动进入静态构建。没有自动上传、远程存储或图片生成。
